《GitHub CEO 复盘 Copilot 四年：130万开发者在用，下一个目标是10亿》

GitHub Copilot 做了四年多，现在有超过 130 万开发者在用，企业付费客户超过 5 万家。最早拿到内部数据时，GitHub 自己都没人信，团队被专门要求回去重新核一遍，核完发现数字是真的。

这是 Unsupervised Learning 最新一期播客的内容。主持人雅各布·埃夫隆（Jacob Effron）来自红点创投，嘉宾是 GitHub CEO 托马斯·多姆克（Thomas Dohmke）。雅各布开场先做披露：加入红点之前，他当过 GitHub 的 COO，Copilot 推向市场那段时间他就在现场。他说那是职业生涯里唯一一次，产品上线后的表现比内部预期还好。

多姆克的路径也少见：在东德长大，柏林墙倒之前就摸上了编程，90 年代初入行，创业公司被微软收购后进入微软，参与了对 GitHub 的收购案，然后一路做到 GitHub CEO。他从 2022 年起反复讲一个目标：让这个星球上有 10 亿开发者。这期播客基本就围绕这个判断展开。

ChatGPT 一发布，客户态度一夜反转

2022 年 11 月 ChatGPT 上线，多姆克随后出差日本、新加坡和澳大利亚。他回忆，从那趟行程开始，客户对话彻底变了。之前聊 AI 编程工具，听到最多的是怀疑；之后变成一句话，帮我们把 AI 用起来，让 AI 进到公司战略里。

他把这轮变化归结为一个第一次：平台级技术转移和消费级普及，第一次同时发生。以前推云计算，销售得先花半小时解释云是什么。这次不用了，CEO 的孩子在用 ChatGPT，父母也在用，老板亲眼见过那个力量，回头就问公司一句：消费应用能做到的事，公司里为什么做不到。

出发点是心流，顺手改写了谁能写代码

聊回 Copilot 最初的设计，多姆克说第一版没有聊天，没有 agent，只有自动补全。补全功能早就存在，大模型把它变成了另一个物种：一次给出 10 行代码，渲染一个完整的测试用例，或者直接告诉你怎么连云。

真正的价值在别处。工程师最大的损耗，是从编辑器切到浏览器的那一刻。你去搜索，浏览器里开着记录你全部生活的标签页，找到答案，复制，粘回编辑器，等你重新进入创作状态，心流已经断了。与其说 Copilot 一开始冲着生成式 AI 去，不如说他们想解决这个更老的问题：让人待在写代码这个最有乐趣的环节里。

聊天加上去之后，自然语言成了第二层杠杆。多姆克的解释是，人用小时候学会的语言思考，没人用代码思考。现在你可以直接问代码问题，让模型把你的代码解释给你听。

有时候，模型比你自己对你更诚实。

还有一层是语言平等。英语主导了技术世界，巴西、阿根廷、南非的孩子想学编程，得先过语言关。现在他们可以用葡萄牙语让 AI 帮自己做游戏。多姆克把学编程类比成学乐器、学画画：学会了不代表要当专业艺术家，只是创造力多了一个出口。10 亿开发者的目标就挂在这条逻辑上。

五年后的开发者，看起来跟今天差不多

主持人问，五年后软件开发者这个职业长什么样。多姆克的回答偏保守：变化速度被高估了，五年后的开发者跟今天差别不大。

理由很实在。他见过的每家公司，每天新写的代码都比删掉的多。大量公司还在维护几十年的代码库，多数银行的主机上跑着 COBOL，那是上世纪七八十年代写的，写代码的人基本退休了。那个年代没有敏捷开发，没有测试驱动，没人写单元测试，这些系统照样得有人管。

AI 对这批存量代码的意义是降低理解门槛。新人进公司，最难的环节往往跟写代码无关，是搞清楚团队的隐性知识：这里怎么部署，怎么加一个库，哪些坑不能踩。现在这些可以直接问 Copilot。他上周在 GitHub Constellation 大会上说，自然语言是开发者手里最强的工具，同时发布了 Copilot Workspace，从想法到生产全程用自然语言驱动。

另一头是积压的工作。GitHub 自己的 backlog 就是满的：一边是企业客户卡着采购的功能，代理支持、策略配置这类没人爱做的东西；另一边是可用性、规模、安全、合规、可访问性这些地基。他的方案叫 Copilot autofix，让 agent 去烧安全和可访问性的债，把人腾出来做创新。

聊到 agent，他给了一个生活化的框架。CI/CD 概念上就是 agent：你推代码，它跑测试，生成日志，出问题报警，给它任务，它还你结果。没人害怕家里的洗碗机，你只会高兴它替你干活。安全工具今天的问题是只告诉你哪里有洞，修还是你自己修，下一代工具应该直接帮你修完。

哪些职业会被替代？他点名了翻译。他设想自己用德语录这期播客，全球听众听到的是英语，还是他的声音，口音随便挑。软件开发整体不会大变，套路和过去一样往上走：开源之前和之后是两个时代，云之前和之后是两个时代，虚拟机换成了容器和集群，AI 只是下一级台阶。

孩子的学习路径他也想清楚了。AI 是叠在代码上面的一层，代码本身不会消失。机器最后跑的还是 CPU 和 GPU 上的确定性指令集，代码是抽象层，从汇编到高级语言到开源库，一直在往上叠。用开源库时你不会去读它的源码，能用就继续用，坏了才 fork 进去调试，那时你才被迫成为那个库的专家。Copilot 一样：孩子输入「给我做个 Python 游戏，要有个精灵角色」，能跑就一直待在自然语言里，一报错就得钻进代码库自己查。两边的理解都得有，但入门门槛低了一个量级。

他管这叫最大的超能力：自己给自己解卡。多姆克 90 年代初学编程，只有书和杂志，没有网可以拨，星期三去电脑俱乐部碰运气，指望有人恰好能解答问题，实在不行就睡觉等灵感，或者给计算机杂志写信，杂志上真的登读者来信。现在的孩子高亮一段代码问 bug 在哪，聊天窗口还记着上下文，会接着建议你试这个试那个。

150 行代码换两行，AI 在放大开源

多姆克刚遇到一个例子。一位科技公司的工程副总裁陪儿子写代码，要把十进制转成二进制，儿子吭哧吭哧写了 150 行。同样的需求丢给 Copilot，答案两行：一行 import 一个开源库，一行方法调用。

这背后是训练数据的惯性：模型学的是真实开发者怎么解决问题，而真实开发者的第一反应就是找开源库。AI 工具会天然把开源推给下一代写代码的人。他判断开源会因此更主流：维护者省力，安全债有人烧，讨论有人总结；贡献者也会变多，因为过去提交 PR 最怕被拒，业余时间做贡献的人尤其受不了这个，现在 AI 帮你按项目规范把代码和测试写对。Meta 刚发布新的 Llama 模型，扎克伯格公开讲开源的重要性，这个盘子只会更大。

雅各布追问了一个投资视角的问题：模型会不会让开源向头部集中？大家不再重复造 75 个功能一样的 JavaScript 库？多姆克的回答是，模型做的事和人一样。人选框架时也会挑维护者多、活得久的 React、Next.js，没人新项目还上 jQuery。而且 Copilot 本来就看上下文，光标前后的代码、相邻标签页打开的文件，都会进提示词，你在 JavaScript 文件里拿到的就是 JavaScript 答案。

企业客户排队要的功能是微调。老代码库加内部 C、C++ 库，模型训练时永远见不到。GitHub 的做法是让企业在组织里挑几个仓库，点一下微调，之后 VS Code、Visual Studio、JetBrains 里自动用上定制模型，全程不用碰数据科学。

抬高平均值，没有赢家通吃

关于幻觉，多姆克的看法很实用：网上找的代码片段本来就不完美，开发者几十年来干的就是拿一段代码改成自己的。原版 Copilot 比 Stack Overflow 强的地方在于它知道你的变量名，知道你光标上面写了什么，给出的答案离完美更近。

我们在抬高平均值，不追求完美。

接下来是扩展（extensions）。多姆克说，几乎没有项目只靠一门编程语言活着，每家公司的平台工程栈都不一样，有人用 LaunchDarkly 有人用 Statsig，有人用 Azure 有人用 AWS。再强的模型也不知道你的栈里有什么。接上扩展之后，你问怎么建 feature flag，它直接给你 LaunchDarkly 的连接，还能在聊天里查开关状态。GitHub 的客户已经在反过来催工具厂商做 Copilot 扩展，因为没人想再登 15 个门户查权限。

模型这块，Copilot 后台同时跑着好几个：3.5 Turbo 负责自动补全，4 Turbo 负责聊天，4o 负责 Workspace，还有没公开的小版本，以及负责任 AI 流水线里一个扫描修复安全漏洞的小模型。多姆克的判断是一个模型统治一切的想法想多了，企业用多个 SaaS，就自然用多个模型，生物科技里治癌症的模型更不可能跟代码模型是同一个。

节奏上有个细节：Copilot 孵化自 GitHub Next 团队，本来定位是第三视野的前沿研究，多姆克说它实际上更像 1.8 视野，很快变成了当前视野。现在 AI 项目的视野最多六个月，六个月后就得重新想。Copilot 已经跨过鸿沟，讨论对象不再是尝鲜者，而是早期大众和晚期大众。这是他见过最快从「能不能成」走到企业主流采用的技术。

聊到竞争格局，他的答案是科技界没有赢家通吃，自认为通吃的后来都被新技术颠覆过。微软明年就 50 岁了，还站在牌桌上，靠的是一次次自我重塑。GitHub 也是，他去年在 GitHub Universe 上说，GitHub 基于 Copilot 完成了重新创立。竞争本身是好事，没有哪场比赛只有一个队自己跟自己踢。他拿 F1 打比方：红牛需要梅赛德斯，梅赛德斯也需要红牛，汉密尔顿连赢那么多年，2021 赛季之后局面反转，比赛才好看。公司玩的是无限游戏，用他的说法，像在玩 Minecraft，一局接一局，没有通关画面，收购和上市都只是并进下一局接着玩。

给创业者的建议有三条。第一，玩长线，每周留出时间想大局，别陷在短期战役里，亚马逊当天送达、特斯拉第二天提车的时代给了所有人多余的紧迫感。第二，持续重构自己，已经没有稳定状态这回事，只有不断进化才能活下来，产品市场契合也没有一步到位这回事，要反复找。第三，说不。公司长到几千人，还是要对绝大多数想法说不，一千个不对一个 yes，创业公司真正的力量是专注，成功了也得保持专注。

主持人不买账的地方，和明天就能用上的事

节目最后，雅各布和红点合伙人乔丹聊了他们的保留意见。乔丹的观点直白：开发者总量会下降，前端工具链先受冲击，后端也会；基础设施和真正复杂的新产品例外。雅各布补了一句，单家公司需要的开发者数量一定会降，QA 岗位已经因为自动化少了一大截，AI 会把这个逻辑推到更多岗位。两人还提到一个现实问题，基础活都被 AI 包了之后，新人从入门到能驾驭复杂代码库的路径，会跟过去完全不同。

两人同时认同一件事：造软件的门槛塌下来之后，会有更多小生意和更多竞争出现，一批非传统开发者会涌进来，这是人类创造力的释放。他们还聊到 COBOL：会写 COBOL 的人退休了，这些老系统撑着美国政府、金融基础设施和医院，已经有创业公司专门做 COBOL 转现代代码的生意，银行迟早得动手，拖不动了。

快问快答里几个信息点值得记下：多姆克认为被高估的是 AGI 和对 AGI 的恐惧，被低估的是 AI 对生物科技和气候的影响。问他怕不怕生成式 AI，他说不怕，兴奋得不得了，还补了一句 AI 会保护我们免受深伪之害。雅各布不太放心，他认识的人里已经有人被 AI 骗过。家里管孩子屏幕时间这件事上，多姆克得专门在 macOS 和 iOS 里给 VS Code 和 Python 加白名单，盼着有一天 AI 能判定编程不算屏幕时间。他家孩子只看过 YouTube 和 Netflix，去爷爷奶奶家看电视会问，为什么不能暂停节目去吃饭。最后一个问题，如果哪天不当 GitHub CEO 了想做什么，他的回答是：那说明有人把我赶出去了，我就去做下一个 GitHub。

最后落到几件明天就能做的事：

  • 装上 Copilot 或同类工具后，把搜索习惯改掉：问题直接在编辑器里问，别切去浏览器，心流断一次，回来要花好几分钟。
  • 接手老项目、老代码库，先用自然语言问一轮：这里怎么部署、这个库是干嘛的、有哪些坑。把团队的隐性知识变成你自己的。
  • 提 issue 或者写需求时，让 AI 先把模糊描述整理成一份规格再提交，描述不清的问题，AI 和人都帮不上忙。
  • 安全和可访问性的积压清单，挑一批先丢给 AI 工具烧一烧，这类活最枯燥，也最容易被自动化。
  • 带团队的人，本周挑一个想法明确说不。一千个不对一个 yes，专注是唯一不会贬值的资源。
