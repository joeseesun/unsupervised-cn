《推理成本三年降了100倍，Tri Dao 说还有10倍，英伟达的九成份额会松动》

先摆三个数字。ChatGPT 发布至今三年，大模型推理成本降了至少100倍；今天全行业大约九成的AI工作负载跑在英伟达芯片上；Tri Dao 判断，接下来一年推理成本还能再降10倍，而那九成的份额，两年内会开始松动。

说这话的人有资格。他是 Flash Attention 的第一作者，这个算法是推理成本暴跌的最大功臣之一；他和 Albert Gu 一起做了 Mamba，Transformer 架构最有力的挑战者之一；他现在是 Together AI 的首席科学家，同时挂着普林斯顿教授的职。Redpoint 的投资人 Jacob Effron 主持这档播客，他说三年前开节目时，Tri Dao 就在自己的梦想嘉宾名单上。

这期节目聊得相当放开。录制前一天，研究机构 SemiAnalysis 发了条推特，大意是：Tri Dao 这些年在英伟达生态里做的优化价值巨大，AMD 和谷歌为什么不直接掏钱，请他去自己芯片上做同样的事？Jacob 说这像极了前两年大模型圈抢那几个能从头训练前沿模型的研究员，天价 offer 层出不穷。硬件圈也开始有同样的稀缺人才逻辑了。

Tri Dao 的回应很实在。他同时和英伟达、AMD、谷歌、亚马逊的人合作，时间大头花在英伟达上，原因很简单：芯片好，软件好，能让他做出有意思的东西。他和 AMD 合作把 Flash Attention 的 AMD 版本整合进了公开仓库。但他现在想得更远的问题是，怎么为所有GPU和加速器设计好用的抽象层，让新同事快速上手，也让AI能接手一部分活。

九成份额，两年内松动

聊到英伟达的护城河，他的拆解很冷静。英伟达强在两件事：芯片设计得好，软件也做得好，开发者在其上构建软件，生态滚雪球。对手一直有，AMD 在这个市场待了很多年，但芯片难做，本质是赌局：你押注两三年后的负载形态，赌错了就白干。

现在牌桌变了。架构层面大体稳定在 Transformer 加混合专家（MoE），负载形态开始收敛，为这类负载专门设计芯片变得可行。他判断，未来一两年，部分工作负载会走向多芯片并存，告别今天的九成押注英伟达。

突破口在推理这边。AMD 显存更大，做推理有天然优势，已经有人开始用。训练这边更难，网络互联是主要瓶颈，英伟达在这里领先。但 Tri Dao 强调，难点已经被大家看清楚了，剩下的是执行。

低延迟这个细分市场已经打响。Cerebras、Groq、SambaNova 主打极低延迟推理，真有客户愿意为速度付溢价。另一头，超大批次、高吞吐的需求也在涨：大规模数据处理、合成数据生成、强化学习训练里疯狂采样轨迹的环节。负载会分化，芯片格局就会跟着分化。

创业公司怎么下注？他的答案很直接：押一个超常规的注。比如赌聊天机器人退潮，视频生成、世界模型或者机器人吃掉一半负载，然后照着那个未来设计芯片。只做通用优化，大公司会用执行力碾过你。

押注也不容易。表面看架构稳定了，掀开盖子全是变化。DeepSeek 的多头潜在注意力（MLA）head 维度特别大，芯片上矩阵乘法引擎的尺寸可能装不下。MoE 让参数暴涨但计算稀疏，为稠密模型设计的芯片就难受。还有新负载，Cursor、Windsurf 这类编程智能体，跑模型之外还要调工具、跑 Python、搜网页，芯片只顾把模型算得飞快，就会忽略怎么跟主机打交道这类问题。芯片设计成了一场持续追赶负载变化的速度竞赛。

硬件可移植是个神话

聊到跨芯片的抽象层，他扔出一句狠话：硬件可移植基本是个神话。

理由很硬。CPU 一年快个5%到10%，老代码照样跑。GPU 完全两样，英伟达每一代芯片都要把软件基本重写一遍，大约两年一次，因为性能提升靠的是更专用的部件：更低精度，新的芯片内部同步方式。连同一家的代际之间都谈不上可移植，跨厂商更难。

所以抽象层哪怕只帮你平滑过渡同一厂商的下一代芯片，就已经值钱。这个赛道现在挤满玩家：Triton 同时支持英伟达、AMD、英特尔的GPU，Meta 的 PyTorch 编译器直接生成 Triton 代码；英伟达自己出了更贴近硬件的 Gluon；Modular 在做 Mojo 语言；斯坦福有 ThunderKittens，还有 TileLang 和谷歌的 Mosaic GPU。他的判断是，大家已经意识到「缺好抽象」是真问题，培训一个能写高性能 GPU kernel 的工程师太痛苦了，一两年内这个方向会快速迭代收敛。

抽象层有代价，他给了个量化标准：牺牲5%的性能换3倍开发效率，划算；牺牲太多，市场不买账。推理市场的竞争已经卷到极致。

抽象从哪来？两个入口。一个从负载出发：推理本质是尽快搬数据、尽快做矩阵乘法，围绕这些原语设计。一个从硬件出发：英伟达把矩阵乘法做得快到离谱，其他操作都成了慢动作，芯片越来越异步，抽象层就得把流水线和同步表达清楚。

那AI自己能不能写 kernel？他把问题拆成两半。全自动这条路还很早：模型能写逐元素运算、求和归一化这类简单 kernel，稍微复杂就产出错误代码。卡在训练数据上，网上能爬到的 kernel 代码，大多是课程作业和三代前GPU的过时文档。解法是拿少量专家数据做种子，接上编译器和性能分析器批量造合成数据。Discord 社区 GPU MODE 已经用 PyTorch 编译器生成了约1万5千对 PyTorch 与 Triton 的程序对。他判断这个问题一两年内能解决。

另一半的结果连他自己都意外：模型跟人并肩干活，已经相当能打。两个里程碑。一个是 O3 和 GPT-5，拿一个函数问怎么优化、该注意什么，高层建议出奇地好。另一个是 Claude Code，写 Triton kernel 出乎意料地靠谱。他喜欢设计架构，但实现部分又重又累，Claude Code 接过去之后，他的整体效率提升了大约1.5倍，也就是50%。Jacob 听到这个数字明显愣了一下。

怎么判断下一代模型行不行？他看一个模糊但关键的指标：模型知不知道自己不知道。编译报错了会不会主动查 profiler，API 记不清了会不会去搜。智能体的核心能力，是知道什么时候该出去找信息。

100倍降本的账本，和下一个10倍

作为 Flash Attention 的作者，Tri Dao 把这三年的降本拆成两本账。

模型侧一本：同样的参数量，模型训练得好得多，数据更多，架构更好，MoE 立了大功。推理侧一本：早期大家没搞清推理的瓶颈是什么，后来才明白核心是数据搬运，权重进出显存，还有 KV cache 这个存着全部历史的部件。于是优化全围着减少搬运转。

量化是最猛的一刀。两三年前一个参数16比特是标配，现在8比特很普遍，新模型直接上4比特，甚至有1到2比特的工作。OpenAI 刚开源的 gpt-oss 总共1200亿参数，大部分层4比特，整个模型塞进大约60GB显存。压到4比特，质量几乎不掉。这背后是相当复杂的量化技术，效果惊人。

架构和硬件的协同设计是另一条主线。Flash Attention 本身就是这么来的：懂硬件的和懂算法的凑到一起，发现瓶颈在显存访问，于是重写注意力算法减少访存。DeepSeek 的 MLA 是新案例，把 KV cache 压缩到小得多的潜在空间，服务效率大幅提升。MoE 越来越稀疏：Mistral 的第一个开源 MoE 模型每层8个专家激活2个，比例25%；现在 OpenAI 的 gpt-oss 是128个里激活4个左右。模型越稀疏，服务海量用户越划算。

下一个10倍从哪来？他给了三个来源，叠加起来一年内就能兑现：

  • 硬件侧2到3倍：架构稳定后，芯片终于可以专门为推理优化，低精度原生支持，网络互联大幅加强，MoE 模型大到要跨卡存放，网络成了关键；
  • 模型架构侧2到3倍：Mamba 这类状态空间模型把历史压缩成小状态向量，替代庞大的 KV cache。这对大批次推理尤其关键，推理时并行跑几百条思维链的时候，KV cache 会变成大麻烦，谷歌 Gemini Deep Think 拿 IMO 金牌靠的就是同时探索多条路径；
  • kernel 层面2倍：越来越多高手涌入这个领域，好 kernel 层出不穷。

三类负载，三种活法

负载在分化，Tri Dao 把它们归成三类。

第一类是传统聊天机器人，要交互感但不能太快，回复秒到反而有点瘆人，你希望对面至少假装想了一下。第二类是低延迟智能体，比如他天天用的 Claude Code，他说如果快3到5倍，愿意付更多钱，因为速度决定人能不能待在心流里。他自嘲是深度工作派，只开一个 Claude Code，被他老婆骂，说别人都同时开四个了。第三类是超大批次，完全不在乎延迟，只要吞吐拉满，典型场景是合成数据和强化学习的 rollout。

合成数据的玩法他举了个例子：航空公司想训练客服智能体，手上只有少量高质量人工数据，然后让模型扮演各种旅客批量生成素材。模型演人类演得出奇地好，比如扮演一个航班延误后在纽约拉瓜迪亚机场发火的乘客。Jacob 接了句梗：人类教给AI的本领里，居然有在机场当愤怒的纽约人。

三类负载对应不同的优化方向，规模化经营的公司还多一张牌：集群级调度。交互查询空闲的时段，把批处理任务塞进去吃掉剩余算力，Together AI 和 OpenAI 的批处理API都能打五折。这个逻辑像网约车平台，高峰期拉人，平峰期拉货，同一张网络赚两份钱。

有人会问，开源推理工具越来越好，vLLM、SGLang 都到了生产级质量，服务商的领先还守得住吗？他的看法是，早期遍地低垂果实，写个像样的 kernel 就能大幅领先，现在基线确实高了很多，但负载演化太快，客户今天要前缀缓存，明天要低延迟，后天做视频又要另一种吞吐画像，总有新活可干。

往后看一两年，他判断负载会继续收敛，智能体是下一个杀手级应用。ChatGPT 是应用层的一次跃变，下一波是模型自己采取行动、收集信息。这不只是把模型跑快的问题，还要接上人类用的工具：网页搜索是简单的，往深了走，飞机工程师要模型接设计软件，金融分析师要模型接数据库。消费级他押的是实时视频生成，影响力会是 TikTok 量级，Together AI 合作的 Pika、Hedra 就在做这个，而视频生成对算力的胃口，会反过来继续推高芯片和推理优化的需求。

和老搭档的分歧：架构到底重不重要

老搭档之间也有一处分歧。Albert Gu 说过，Transformer 不会是终极答案。Tri Dao 当场回应：

“我爱 Albert，但这一点上我们可能有分歧。通往 AGI 甚至 ASI，现有架构可能就够了。问题是要花多大代价。”

更好的架构也许让你早到一两年，或者用十分之一的成本到达。他给了个背景数字：全行业每年砸在AI基础设施上的钱大约5000亿美元，他特意补了一句别引用得太精确，量级差不多。照这个花法再乘10倍，有点不现实。架构研究的价值就在这里，也许现在这个投入就够了。

他现在挂在嘴边的词是「推理优先的架构设计」：反正大部分算力花在推理上，架构就该为推理设计。他把目标拆成一个公式，每美元买到的智能，等于每次浮点运算产出的智能，乘以每美元买到的浮点运算。前一半靠架构、算法、数据，后一半靠硬件和 kernel 优化。MoE 持续稀疏化是一边，他和 Albert 的状态空间模型是另一边，英伟达已经用 Transformer 加 Mamba 的混合架构训练出好几个高质量模型，成本更低，推理性能更高。

机器人是他新开的研究方向。人形机器人进家庭还要几年？他说不知道，五年，十年？但这个领域有让他着迷的问题：控制关节要极快的小计算，规划路线要慢而重的推理，这种多时间尺度的信息处理，跟状态空间模型的思路天然相通。未来的机器人系统大概是用语言、视觉、音频、世界模型初始化，再把它们缝合起来，怎么缝是最大的问题。

聊到学界和产业界的分工，他把学界比作风投：政府出钱，让你大量试错，指望5%到10%的想法能成。注意力机制虽然因谷歌的论文成名，实际出自 Mila，Bahdanau 和 Bengio 那批人的工作；Adam 优化器和 LayerNorm 出自多伦多的 Jimmy Ba。今天架构里的很多零件都来自学界，大公司和创业公司负责快速执行、理解市场、砸钱放大。现在的融资环境有点扭曲这个分工，Ilya 的 SSI 明说近期不做产品，照样有人抢着给钱。

快问快答环节，他的几个判断值得记下：过去一年他改变的想法，是模型对他的日常工作出奇地有用，1.5倍的提升远超预期；开源和闭源模型的差距一年内会缩小，因为强化学习阶段的扩展更依赖工具链而非纯算力；被低估的方向是数据，合成数据和用模型改写数据的影响被严重低估了。

明天就能用的三件事

信息量太大，收个尾，给三件明天就能上手的事。

第一，检查你的用量结构。做智能体或编程场景，延迟直接决定产出，值得为低延迟付溢价，甚至测一测 Cerebras、Groq 这类专用方案；做合成数据、批量处理这类不在乎延迟的活，切到批处理API，五折就在那里，很多团队到现在还没切换。

第二，把 Claude Code 或者你顺手的智能体编程工具用到重活上。Tri Dao 这样的顶级专家都拿到了50%的效率提升，普通开发者在实现类工作上的收益只会更高。判断模型好不好用，看它知不知道自己不知道，会不会主动查文档、看报错、跑 profiler。

第三，把「可移植」的预期降下来。GPU 世界里连英伟达自己每两年都要重写一遍软件，指望一套代码无痛跨芯片不现实。更务实的路径是押注 Triton 这类抽象层，接受5%左右的性能损耗，换回数倍的开发效率。

九成份额、100倍降本、下一个10倍，这些数字背后是同一个判断：AI 基础设施远没有定型，负载每变一次，牌桌就重洗一次。Tri Dao 用 Flash Attention 证明过一次，个人和小团队抓住结构性的变化，就能撬动整个行业的成本曲线。下一次机会，大概率就藏在那三类负载的裂缝里。
