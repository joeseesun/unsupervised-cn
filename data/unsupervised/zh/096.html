《Transformer 论文合著者卢卡什·凯泽：模型学会一个概念，得先烧掉一万亿 token》

复现一篇老论文，卢卡什·凯泽以前要花三个星期。今年他把活交给 Codex，两天跑通。他自己算了笔账，效率大概是原来的五到十倍，而且现在习惯同时开三个任务挂着跑。

这个数字得看是谁说出来的。凯泽是 2017 年《Attention Is All You Need》的八位作者之一，Transformer 就出自这篇论文，今天所有叫得出名字的大模型，底座全是它。他先在谷歌把 Transformer 做了出来，后来加入 OpenAI，亲历了推理模型那次转向。他以前是数学家，原话是，从没想过有生之年能跟计算机在高水平上聊数学，这事现在真实发生了。

在 Redpoint 合伙人雅各布·埃弗龙的播客 Unsupervised Learning 第 89 期里，这位写出 Transformer 的人给出了一个判断：Transformer 大概率还会继续赢，但它学习的方式跟人类差得很远，可能真的存在更好的东西。

一万亿 token 才学会一个概念

埃弗龙把最尖锐的问题放在了开头：光靠推理，模型能走到通用化吗，还是需要全新的方法？

凯泽先给了肯定。现在的模型配上推理、智能体和工具，能干的事两年前他根本不敢信。一个下一词预测器，加上思维链、强化学习和工具调用，就能跟他讨论真正的研究问题。然后是转折。

“人们说美国人会在试完所有错误选项之后做正确的事。LLM 也一样。它们确实能学会一个概念，但要把其他路全走完。先烧掉一万亿 token，把所有表层规律学完，等表层解释不了了，才终于去学概念本身。人不是这么学的，人有时凭几个例子就把概念造出来，哪怕造得不太对。”

模型缺的就是这块：某种更接近长期理解的东西。这种直觉在圈子里已经成了气候，好几个实验室在押注后 Transformer 架构。杨立昆喊了很多年，神经网络这个名字是冲着模仿大脑去的，实际上跟大脑差得远。反方观点也硬：模型从来都是拿一万亿 token 喂大的，没人针对小数据优化过它，真限制数据量再去调，Transformer 还能更强。凯泽的立场很诚实：谁赢，我不知道。

他举了个日常例子。Waymo 的自动驾驶他一直夸，结果最近因为处理不了高速上的施工区，直接把高速驾驶功能停了。施工区问题折腾了好几年，模拟里程几百万英里，真路也跑了不少，还是过不去。没有哪个十几岁的孩子会有这种困扰。孩子懂的道理很简单：施工区就是施工区，城市的算，高速上的也算。

小模型那边有些苗头。TRM、HRM 这类小得可怜的模型，加一点循环结构、换一点损失函数，在数独和 ARC-AGI 这类测试上把纯 Transformer 打得没脾气。问题在于这些招数能不能放大到语言模型的量级。凯泽猜注意力机制大概率会活下来，但可能需要别的东西配套。

多模态是另一处让他觉得架构不对劲的地方。人每秒接收的海量感官信息，从来不用逐像素预测的方式去学。Transformer 太串行，塞一张高分辨率图片得切成小块慢慢消化，每毫秒一张图它根本吃不下。Thinking Machines 最近做的多流 Transformer，改动很小，方向却可能很对。他吐槽自己用 Codex 的日常：模型在跑一条命令，他想插句话纠正方向，得干等三分钟。人看、听、说是同时进行的，模型也该这样。

圣诞节那一跳，连内部人也说不清

聊编码智能体，凯泽的时间线很明确：Codex 时代是去年圣诞节开始的。之前 Codex 和 Claude Code 都存在，大家也都在用，圣诞节前后突然就完全不一样了。他自己天天用，圈子里人人都在用，用他的话说，研究员群体陷入一种“轻度癫狂”，停不下来。

有意思的是原因说不清。从 RNN 换到 Transformer，功劳归谁很清楚。这次不一样，模型、外壳（harness）、后训练都动了，新的预训练模型也来了，叠在一起跳了一大步，没人能指认出决定性的那一项。凯泽说他自己都不知道，也不确定有谁真的知道。

长上下文的解法更能说明问题。现在的方案是把东西写进文件，给模型一个 grep，让它自己建索引、自己找。凯泽说，五年前要是有人跟他说这是长上下文的答案，他会说这是绷带，不是药。现在他不这么看了。

“机器学习本身就是个各种补丁的集合。Dropout 是个补丁。我们不评判方案长什么样，只评判它好不好使。它好使得很。”

他更喜欢 Codex 的一个具体原因是压缩（compaction）做得好，线程能一直续下去。为什么好？他觉得一点都不神秘，提示词写得好，再上点强化学习，就出来了。

OpenAI 公开说过，目标是今年 11 月做出研究实习生水平的智能体。凯泽觉得接近了，但得盯紧。他放过一次整晚，目标是把困惑度降下来，结果模型只会做无聊的小调整。还有一次复现论文，模型自作主张加了一个辅助损失，整个训练直接飞了。类名和函数名可以不看，损失函数、批次、训练动态这些必须全程装在脑子里。

智能体改写的是研究本身

凯泽的原话是，这是他二十年研究生涯里工作方式最大的一次变化。

变化有两层。第一层是速度，三周变两天。第二层是并行，以前一次做一件事，现在同时开三个任务挂着跑。

朋友问他，代码都不看了，人会不会变笨。他想了想，答案是相反。以前写代码，调试时盯着细节，抬头时大局忘了，想起来的时候往往已经错了。现在他只保持机器学习层面的全盘控制：损失是什么，批次怎么走，实验该出什么结果。细节全交给智能体，人反而一直在心流里。他甚至觉得这让自己更锋利了，因为每一步都得验证，都得知道模型在干什么。

可验证性是个光谱，品味不在上面

强化学习有个老问题：代码和数学能验证，别的领域怎么办？

凯泽觉得这个问题问歪了一点。数学的“可验证”被高估了，证明大部分没有形式化，Lean 能做但没人做。前端代码也不像竞赛题那样有标准答案。真正的图景是个光谱，从竞赛题一路滑到“说不清”。

他自己的小项目是把诗翻译成波兰语。听起来完全没法验证，但拿模型当验证器，押韵能查，文化梗能查，能抓住不少东西。问题是，能验证一大堆指标，最后还是可能毫无品味。品味没法用语言描述，能用语言描述的东西早就可验证了。

但这堵不死。图像生成那边已经有人这么干：训练时找一堆人对着图点“好看”“不好看”，就这么个稀疏信号，图像真的开始变好看了。凯泽的总结是，强化学习就是有个老师告诉你好坏，任何洞都能靠蛮力堵上。麻烦在于，每堵上一个洞，瓶颈就转移到下一个没堵的洞，永远在打地鼠。要是有一个像大脑那样洞少一点的学习方法，日子会好过很多。

泛化倒是真实存在的。OpenAI 的 GDPVal 基准测的就是跨行业任务，法律压根没进 RL 流水线，Harvey 那边的体验是能力自己冒出来，或者稍微点拨几下就开窍。但泛化的形状很怪。IMO 级别的几何题，模型卡了很久，别的领域再难都能解，几何就是不行。后来靠什么解决的？靠的居然只是更多的几何题，空间理解的数据一条都没喂。它在泛化，但用的是外星人的方式，从这儿能推到那儿，看着很近的两个点，它就是推不过去。这也是信任难建立的原因，没人知道哪里藏着一条没补的尖刺。

桌子底下的显卡，超过了当年的机房

凯泽买了块 RTX 5090 放在家里桌下，BF16 精度下大约 200 TFLOPS（标称 400，关了一部分）。当年做 Transformer 研究用的 GPU 是 9 TFLOPS，一台机器 8 块卡，总共七八十 TFLOPS。他桌下这一块卡，顶当年五台机器。几千美元的设备，塞厨房里都行，当年整篇 Transformer 论文的算力就这么点。

更刺激的是大脑算力这个老话题。他在谷歌时常听人估，模拟人脑要 1 到 100 PFLOPS，当时觉得还得几十年。现在一块消费级显卡摸到了下限，理论上几百到几千美元的成本，一天跑完一个人一年的大脑处理量。凯泽说，要是有人对大脑怎么学习真有想法，大学里一个研究者就能在几天内把“一个人的童年”跑一遍验证。他觉得这比训练超大模型更有意思。

智能体还顺手解决了另一个瓶颈。RNN 这类串行结构在 PyTorch 里慢得没法用，要快就得手写 CUDA 内核，而手写 CUDA 内核是件苦差事。现在可以让智能体写，单元测试对着慢版本一跑，对上了就能用。硬件没变，能试的想法范围变了。

所以凯泽对学院派特别乐观。算力小的时候只能做小修小补，现在一台机器就能跑到 nanochat 那个量级，Karpathy 的开源项目，一块显卡几个小时训出 GPT-2 水平的模型，这个规模上做的已经是真正的实验了。他鼓励大家去做怪东西，多发大胆的论文。他自己的黑历史是 Transformer 论文前一年在 NeurIPS 发过一篇“注意力不是必需的”，用主动记忆替代，结论不完全对，但探索错路本身有价值：人类擅长从错误方向里拧出正确方向，模型恰恰最不擅长这个。

押注的艺术：Anthropic 为什么先拿下编码

编码市场为什么是 Anthropic 先跑出来的？凯泽的答案很直接：Anthropic 押对了编码，一部分原因是它在聊天上根本打不过。当时 OpenAI 的全部注意力在 ChatGPT 上，十几亿用户，忙不过来。Anthropic 转身把编码做成主战场，等 OpenAI 反应过来，追赶已经要费劲了。

教训是什么？AI 隔一阵就来一次洗牌，押注要押明天的东西，哪怕今天的东西看起来不可战胜。ChatGPT 是 2025 年最惊艳的 AI，到 2026 年就不算了，2027 年说不定又换一茬。

OpenAI 自己也有过一次漂亮的押注。凯泽在的时候，公司决定全面转向推理模型，推理和预训练同等重要。当时推理模型话少、慢、个性难调，两条产品线并行很痛苦，统一花了好久。但这一步走对了，到现在还有大实验室在 RL 质量上追不平。他的担忧是，公司变大二十倍之后，这种 wild bet 的能力还在不在。谷歌就是参照系，什么都不敢扔，被批评错过自己的发明，好处是追起来快。Google I/O 之后发的 Antigravity 2，凯泽打开看，已经分不清哪个是它哪个是 Codex 了。但小杯的 Flash 模型跑他的 Codex 式任务还是不行，圣诞节那道坎没迈过去，他猜是因为蒸馏自 Pro。

开源和闭源的差距，他的判断是会持续存在但不会拉爆。蒸馏出来的模型永远差一口气，mini 模型用着都挺好，直到某次翻车赔掉的时间让人乖乖回去买大杯。实验室会防着被蒸馏，但不至于往死里防。国家层面会要主权模型，医院和警察局的系统不能押在一家会宕机的公司上。需求两头都在，格局就稳。编码产品本身，他觉得市场够大，容得下两家，真正的问题是怎么把能力带给其他职业。Codex 开口就问 GitHub 仓库地址，会计听完直接劝退，Anthropic 拿 Claude Cowork 做更友好的包装，方向是对的。

凯泽管这些编码智能体直接叫 AGI。他的说法是，我们可能有一天会像越过图灵测试那样越过 AGI 这个词，从此没人再争论它算不算。走出旧金山的泡泡，很多人还把 AI 当成圣诞节之前的样子，默认它不会再变。他的评价很直接：这是错误的对待方式。

快问快答里有两个细节值得记下。一是凯泽承认自己被打脸了，他以前不信研究实习生这么快会出现，现在连编程编辑器都不打开了，改代码全靠说。二是安全，他的立场一直是“不用太恐慌，但别躺平”，眼下真正该盯的是小风险：模型黑进系统、电网出事这类，以及保留随时关掉数据中心的能力。Karpathy 去 Anthropic 做递归自我改进（RSI）的消息，凯泽也泼了点冷水：想法的空间太大，绝大部分是错的，所以才叫研究。就算智能体到了十倍研究员的水平，高效搜索也不保证撞上正确答案。当年一大群最聪明的人围着这些问题转了很多年，也没转出来。

凯泽在结尾说，这是机器学习研究最激动人心的时代，桌下有强显卡，手边有能干的智能体，大实验室在推 Transformer，空气中飘着别的东西的味道。他劝所有人去试自己的想法，哪怕失败，有了智能体，失败的成本也低了。

落到明天就能做的事，这期播客给了四条：

  • 把复现论文、重写老代码这类活交给智能体，五到十倍的提速是真实存在的。同时开三个任务，人只盯机器学习层面的关键变量，损失、批次、训练曲线。
  • 关键任务用大杯模型。小杯省钱，但一次翻车赔进去的时间，比省下的钱贵。
  • 做产品的人记住 Anthropic 的剧本：今天最热的赛道挤满了最强的人，押注要押下一个圣诞节的跳跃会发生在哪里。
  • 用智能体的手感有学习曲线，前期别嫌麻烦。凯泽的原话是，信任的建立有门槛，但回报是确定的。
