《精益创业作者开AI实验室：不设经理，一个土耳其学生搞出Llama 3微调突破》

先看一间奇怪的公司。投资人问它专有技术是什么，答不上来；问目标客户是谁，答不上来；问五年财务规划，还是答不上来。按剧本这种公司拿不到钱，现实是几乎每一位被邀请的AI行业内部人士都投了，拒绝的只有一个，传统机构的投资人还主动找上门。

这家公司叫 Answer.AI，定位是「AI时代的贝尔实验室」。两位创始人都来头不小：Eric Ries，《精益创业》作者；Jeremy Howard，Fast.ai 创始人、前 Kaggle 总裁。2024年5月，两人一起上了 Redpoint Ventures 合伙人 Jacob Effron 的播客 Unsupervised Learning。

这间公司有多不寻常，一个细节就够了。Llama 3 高效微调的突破，由一位住在土耳其的硕士生 Karim 一个人完成。没有立项会，没有经理排期，因为公司根本没有经理。Karim 觉得这事值得做，就动手了；同事觉得有意思，顺手搭了把手。

Demo 太好看，是 AI 创业最大的陷阱

Jacob 一上来就抛出那个绕不开的问题：《精益创业》讲小步试错、快速验证，可现在的AI公司动辄融巨额资金，砸进模型和算力，产品还没影就烧掉几亿美元，这套方法论过时了吗？

Eric 的回答很干脆。他做过创业公司，也做过大企业内部创新，现在的AI圈让他有种「回到未来」的感觉。问题出在 demo 太好看了。AI 能做出魔力般的演示，创始人盯着屏幕看它写代码、写文案，很容易说服自己：这次不一样，产品好到不需要验证。

他见过上一轮的剧本。很多人把 SaaS 那套打法原样搬进AI，用他的话说，拿蜡笔把标签划掉重写，.com 改成 .ai，其余全不动。靠这个融资没问题，Eric 不反对别人拿钱，但他指出一个结构性风险：产品市场匹配的问题被推给了下游。做 API 的公司看到调用量暴涨，就默认客户会替自己完成验证。可从模型到终端产品，中间隔两层、三层、四层都很常见。只要这条链路的组装方式和软件时代不同，中间那些公司会死一大片。

他给的建议只有一条，从德鲁克那里借来的：企业的目的是创造顾客。指标背后全是活人，API 调用量只是人在做事留下的痕迹，离终端用户太远，迟早出事。

还有一点常被忽略。Eric 说，AI 的经济学更接近制造业、深海钻井、核电站这类重资产生意，有真实的运营成本和市场风险。精益方法靠小额试错对冲不确定性，而巨额算力账单本身就在放大风险，两股力量方向相反。

压路机前捡硬币：护城河焦虑怎么破

Jacob 提到，Perplexity 的 CEO Aravind 之前上过这档播客，说很多创业者被「护城河」三个字钉在原地，明明看到了真实需求，却因为想不清防御性迟迟不动手。

Eric 用了一个老比喻：在压路机前捡硬币。

「你可以在压路机开过来之前冲进马路，捡起硬币，再跳出来。聪明的话还能反复这么干。唯一的代价是，摔一次就全完了。」

OpenAI 这样的平台理论上能碾压任何人，它随时可以决定做你做的事。但巨兽再快也只有一个身子，能同时推进的方向有限，绝大多数用例它顾不上。他回忆，平台战争是科技行业的老节目，Mac 对 PC，英特尔对摩托罗拉，x86 对 ARM，社交网络那场更是血腥。这一代创业者太久没经历过，忘了行业分析本来就是创业的基本功。

但 Eric 最终站 Aravind 一边。分析有用，能排除掉那些「就算成了也没经济性」「就算赚钱也睡不好觉」的项目。可如果一件事你真心相信，就算聪明人断言你死定了，这也不该成为放弃的理由。前提是谦逊要体现在公司结构上：放弃分析的人，比谁都更需要快速迭代。有人以为不靠分析就不用迭代，正好相反，正因为不确定假设对不对，才要把公司建成随时能转向的形状。

对那些言之凿凿预测模型能力、消费者偏好的发言，他一律不信。更好的策略是准备好迎接一系列可能的未来：愿景坚定，转向灵活。

他还补了一刀。行业通常要过几年才出现「精益创业过时了」的文章，然后被点名的公司轰然倒塌，Quibi 就是现成例子。这一轮直接跳过了写文章的阶段，第一批不做迭代的初创已经在出事，大家在用快进的方式重演炒作周期。

一间没有经理的研发实验室

再说回 Answer.AI 的形态。它注册为公益企业，写进章程的使命是让尽可能多的人从AI中获益。这是 Fast.ai 的延续。当年 Jeremy 和妻子 Rachel 做出第一门面向非博士人群的深度学习公开课，外界普遍觉得幼稚可笑；几年下来，这条路被证明走得通。

Jeremy 说 Fast.ai 有个遗憾：课程、软件、研究成果全都要求很强的编程背景，这把受众限制在全球人口的百分之一以内。一门想让AI普及的事业，先把自己锁死在小圈子里。大语言模型让普通人用自然语言就能操作计算机，这个口子必须抓住。另一个动机是担忧：他和 Rachel 创办 Fast.ai，本意是对冲AI带来的权力集中，几年过去，集中化反而在加速。

于是有了这间盈利性研发实验室。Eric 解释，过去一百年，研发的 R 和 D 越分越开，学术界和工业界都在做大量与应用完全脱钩的研究，爱迪生看了都会觉得奇怪。他的主张很偏门：最好的研究，发生在研究者本人和应用直接耦合的时候，迭代回路要从终端用户一路连到科学问题，再连回来。

他讲了个故事。某次给数据中心做新技术，实验室里的科学家在攻克极难的能效优化，难度高到需要基础物理突破，他开玩笑说那得先拿个诺贝尔奖。第一次把 MVP 拿给数据中心建造商看，对方问的第一个问题是：这东西占地多大？为了省电，设备体积要大 300%，而建造商关心的是机架数量，你占我的地，给别人省钱？事实回到实验室，一位初级研究员五秒钟就想通了：换一组权衡，科学问题就换了一个，继续攻关。Eric 感叹，科学家拼命解的，往往是对客户毫无价值的题，把回路接通，突破才会持续发生。

研究实验室史研究者 Eric Gilliam 分析过 Answer.AI 的模式，概括为「长缰绳，窄栅栏」：栅栏是两位创始人早期定下的研究论题，缰绳是放给每个人的自由。Karim 的突破就是这么来的。融资也带着运气，Jeremy 在另一档播客里随口提了想做研发实验室，主持人 Alessio 当场回了一句：我们明天就能给你 term sheet。

把成本降十倍：大厂嫌无聊，他们当使命

Answer.AI 的研究论题很清晰：业界在从零训练基础模型上投入过量，在镀金硬件上投入过量，对资源受限的真实世界投入严重不足。所以招人专挑在乎效率的，很多人自己就有资源受限的经历。

Jeremy 去湾区一家大实验室交流，对方听完直问：这玩意儿是干嘛用的？听起来只是把成本降下来。「只是更便宜」在巨头眼里无聊透顶，在 Answer.AI 眼里就是使命本身。成本降十倍，能用上的人多十倍，这就是可及性的定义。

便宜还有更深的含义。Eric 说，工业演化史上，程度的差异积累到某个点会变成性质的差异。这是软件行业多年来第一次面对真实的供应链约束：电力接入、机房建设、全球 HBM 内存的产能。推理成本降下来，能解锁今天根本做不了的场景。

他给了一个具体画面：今天的模型全是「失忆症患者」，电影《记忆碎片》的主人公，每段对话都靠上下文窗口这张小纸条记事。如果微调便宜到可以持续进行，每个智能体都能在一台便宜的虚拟机上不断被训练，带记忆、超个性化的AI服务就成立了，甚至可以为单个客户配专属资源。

Jeremy 用爱迪生补了一层。电灯泡式的发明人人会夸，可当年真正难的是另一类：把电能变成唱片机，变成冰箱。这类应用不需要天才去构想，需要的是几十万次枯燥的实验把它做实用。爱迪生因此被讥讽不搞「真科学」，他不在乎。AI 圈现在的问题是炫酷 demo 太多，部署出去的产品太少，缺的正是可部署性、成本、易用性这些脏活。

为了养出这种手感，Answer.AI 给每个员工每月 500 美元额度，买任何AI产品，往死里用。团队里人人都用 Copilot 和 Perplexity，分歧出现在长尾：有人发现 Cohere 的 Command R+ 在检索上有一组独特的优缺点。Jeremy 说，机会就藏在这些差异里。

智能体被高估了，法律和教育藏着大机会

快问快答环节，Jeremy 的判断很干脆：当下被高估的是智能体，被低估的是资源效率。

依据来自数学底层。大语言模型做的是线性化的子图匹配，训练数据里几乎原样出现过的规划序列，它能完成得漂亮；需要真正新规划的序列，它做不了。所以帮你处理邮件、给 HTML 加 CSS、迭代调试常见 Python 报错的智能体会很好用，指望智能体独立做出研究突破，方向就错了。他自己的算法大多只有四五行代码，从来没有任何语言模型帮上过忙，因为这些算法定义上就不在训练数据里，要是在，他自己就能写出来。

高确定性的机会在语言密集的行业，两人点了两个：法律和教育。合作的一位律师说，律所就是一台超大的语言模型，文本进，文本出。

法律的问题在于被当武器用。Jeremy 说，富人机构用诉讼拖垮穷人机构，社会居然默认了这套玩法。把高质量法律服务的价格打下来，法律被当武器的机会就少一分；美国还有大量行业靠法律门槛把人挡在门外，这也是他想拆的墙。Answer.AI 团队里已经养了三位全职律师。

教育那头，Jeremy 是在家教育孩子的父亲，花了几千小时读教育学术文献、听教师访谈。他的观察：老师很棒，但制度逼着一群孩子同一时间走同一条路，个性化空间极小，他亲眼见过女儿挣脱这套约束时的状态。语言进、语言出，恰好是模型擅长的事。

安全法案的悖论：管得越严，越危险

节目播出前一天，Jeremy 发文批评加州 SB 1047 法案。这个法案想对训练基础模型设置安全审查，出发点不难猜：飞机、汽车、牙膏都有安全标准，模型凭什么例外。

Jeremy 为这个问题做过功课。一年前，GovAI 联合 OpenAI 等机构发布过一套同类立法框架，他拿到底稿，找了 70 多位各领域专家做红队访谈。访谈做完，结论朝着相反方向走：这类政策大概率无效，而且会让 AI 变得更不安全。

核心逻辑是双用途。模型和纸笔、计算器、互联网是同类技术，没人能保证它只被用于好事：买你计算器的人可以拿去算核弹参数，买你纸的人可以写恐吓信。要「确保」模型安全，实践上只剩一个办法：别把模型给出去，只提供套壳服务。ChatGPT 是产品，安全层可控；Llama 3 是裸模型，能下载权重，能微调，能看梯度和激活值，还能做聪明的缓存。裸模型的能力强得多。

悖论就在这里。立法要求确保安全，等于禁止发布模型，模型就变成被少数巨头和国家垄断的稀缺品，大家关起门来竞赛，外部无从研究它的能力边界，透明度归零。原本千万人能用来做防御的事，网络安全、疫苗研究，全被锁进保险柜。试图确保双用途技术的安全，必然制造权力集中、竞争黑箱和透明度下降。

Eric 从另一个角度补了一刀。他不反对前沿实验室，探索 AGI 本身是正当使命，商业化只是维持研究的手段。真正的问题是融资引力把太多创业者从「有用」吸向了「科幻」，一大堆不需要 AGI 就能解锁的应用没人做。Answer.AI 有位重量级AI安全倡导者做投资人，他想通了一件事：如果市面上只有前沿模型，人们只能拿最重的模型去接真实世界系统，这本身就是不安全。便宜、微调过的小模型，定义上就更安全。没人提供这个选项，大家就只能默认选危险的那个。

对实验室本身，Eric 的观察是它们正在精神分裂：一头是安全研究和 AGI 愿景，一头是越来越庞大的商业机器，两边的人互相不理解，有些商业团队只关心数字涨。内部张力大到可能把公司撕开。他给的药方抄自丰田生产方式：自己去看，坐到客户旁边，把客户用成功当成自己的责任。

快问快答还有几个尾巴。Eric 最看好的外部公司是 Perplexity，理由是速度；Jeremy 选了 Groq，理由同样是快，而且技术路线在数学上站得住，他还补了一句：Meta 才是当下对AI最重要的组织。被问什么突破会改变他们的判断，Jeremy 点了两个方向：能源和资源需求的骤降，以及超越自回归逐词预测的新架构，杨立昆团队的 JEPA、文本扩散模型都在这条路上。Eric 的答案更玄：也许问题出在人类对认知本身的理解上。现在的LLM好比用 Minecraft 方块搭出一台计算器，能算，但极笨重；更笨的办法是穷举所有方块组合，等某个组合碰巧能算数。他说，说不定哪天醒来会发现，我们用蛮力撞出了某个关键认知算法的低效版本，直接把它写出来才是真突破。

节目结尾还有个彩蛋。Answer.AI 这个域名是 Jeremy 多年前囤的，当年他还买过 emergent.ai，页面上只放一句话：AI 尚未到来。那是他的金丝雀。

最后收个尾，这期节目里明天就能用的东西，挑了五条：

  • 沿价值链往下捋：不管处在哪一层，找到终端的终端用户，确认整条链上有人真的完成产品市场匹配，别拿 API 调用量自我安慰。
  • 把公司建成能转向的形状：分析可以排除坏选项，但别让护城河焦虑阻止动手；放弃分析的人，迭代频率要加倍。
  • 判断智能体任务先看训练数据：流程几乎原样出现在语料里的任务放手做，需要新规划的任务先放一放。
  • 把降本当产品能力：成本降十倍会解锁新场景，从持续微调、个性化记忆开始想。
  • 给团队发AI订阅预算：Answer.AI 每人每月 500 美元，用出来的差异就是团队的认知地图。
