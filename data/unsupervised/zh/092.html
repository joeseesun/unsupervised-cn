《Claude Code 一年 25 亿美元 ARR,Swyx 把 AI 编码大战讲透了》

Claude Code 上线刚满一年，ARR 冲到 25 亿美元，统计口径还有争议，量级没人质疑。OpenAI 的 Codex 没有公开数字，圈内按 20 亿估。Cursor 传闻也是 20 亿。一年前，这三家的编码收入加起来约等于零。

这是 Unsupervised Learning 第 85 期，Redpoint 投资人 Jacob Effron 和 Latent Space 主播 Swyx(Shawn Wang)的年度串台。Swyx 的位置很特殊：他创办了 AI Engineer 大会，现在一个季度办一场，刚从伦敦的 AI Europe 回来，又在 Cognition 任职，坐在 AI 编码战争的第一排。

这期信息密度很高：基础设施是否终于稳定、编码大战的终局、卖给智能体的生意怎么做，还有两个他自己承认看走眼后改口的观点。下面拣干货说。

基础设施终于不打地鼠了

LangChain CEO Harrison Chase 最近发了条推：AI 基础设施终于给人一种稳定感。这话从他嘴里说出来分量不轻。LangChain 过去三年基本每年推倒重来一次，从 LangChain 到 LangGraph,再到 deep agents,像在打地鼠，模式怎么变他就得跟着搬。

Swyx 对「这次不一样」这类判断一向警惕，但他承认这次有实据。集成的打包方式收敛到了 Skills:一个 markdown 文件，加几个脚本，没有比这更简单的格式了。智能体的共识定义也基本定型：LLM,加工具，加循环，加文件系统，检索和 Skills 是标准配置。

变化没有停，只是换了位置。实时交互、子智能体、记忆这些「学科」还会继续折腾。他的建议很实用：别把名声押在「我们到站了」这种论点上，风向变了就跟着变，不丢人。

Jacob 补了一个视角：应用层和基础设施层的生存难度完全不同。Sierra 的 Brett Taylor 这类应用层创业者公开说过，模型每进步一轮，愿意把产品推倒重来。他们敢这么玩，因为手里攥着粘性的终端客户。基础设施公司面对的是开发者，一群更挑剔的买家，走的时候干干净净，连数据库里的工作负载都能整个迁走。

水平方向还有机会吗？Swyx 认为有，但形态像「AI 时代的云计算翻版」，典型是沙箱公司。他的原话带着泼冷水：「这其实就是另一种算力，大家别太激动。」不过工作负载确实巨大。最抗周期的还是垂直打法：做客户的外包 AI 团队，把最新的模型能力翻译给不会自建团队的公司。

编码大战的牌面

有人翻出 Claude 的用例分布：编码占了 50%,法律、医疗这些加起来分剩下的。于是有条很火的推说，新创始人该去赌那些空白行业，做追赶游戏。

Swyx 的反驳搬出了苹果和谷歌的旧账：一年前编码占比还是 10%,现在 50%,凭什么认定它明天就停？押动量还是押均值回归，是这一轮最贵的判断题，押错的人只能眼看动量方把钱赚走。

现在这个阶段，他叫它「能力探索期」。花得多的人被奖励，花得少的人暂时没有。榜单上晒 token 消耗成了新的军备竞赛，质量暂时没人细看。这有点难看，但他觉得方向上没错，因为整体上大家对 AI 的使用还远远不够。

极端案例在 OpenAI:有位工程师每天跑十亿 token,按市价约合一天一万美元。大部分产出可能是 slop,但按 Swyx 的说法，真出现新能力，他会比你先发现，因为他在试，你没在试。发现下一个玩法的人，永远是烧得起算力、活在边缘的那批人。

补贴地图也值得看。Anthropic 走高价限量路线，控额度、控模型发布节奏；Codex 反着来，SDK 随便接，额度动不动重置，Gemini 也在大力补贴。Swyx 的建议：能薅就薅，200 美元一个月的订阅就够当能力探索者，大多数人连这个量都没跑满。

终局呢？他押现状延续：两个大玩家，加一圈服务细分场景的长尾。过去六个月，经济学、品牌、价值主张都没出现足以改写格局的变化。变量有三个：微软哪天醒来，意识到自己手里有 GitHub;Meta 的 MSL,Alexandr Wang 在早餐会上明说要攻编码；还有中国厂商，智谱 Z.ai 的 GLM 一直在追。

大厂自己也在分心。OpenAI 在推超级应用，Anthropic 在扩地盘，Claude Code for Finance、Claude Cowork 都在路上，金融和医疗是下一批目标，金融的变现路径明显更清晰，医疗更棘手。Cursor 和 Cognition 反而只专注编码。模型厂商注意力分散的地方，就是应用公司的生存空间。

企业侧还有个信号：大公司想要一个模型厂商之外的专属伙伴。模型 lab 信奉极简，把宝押在模型本身；agent lab 帮你走完最后一公里。两种打法都成立，但企业明确愿意为后者付钱。

聊天机器人那边是另一番景象。Jacob 提到 ChatGPT 增长停滞，Swyx 的判断是品类问题，份额问题倒是其次：整个消费级 AI 都在平台期，编码那边却整个品类在指数增长。编码市场里还有个反常识现象：多数人评价 Codex 已不输 Claude Code,甚至局部更好，但先递出魔法体验的 Claude Code 粘性惊人。第一个把新体验送到你手里的那家，会占住很久。这也让所有实验室都相信自己有机会，下一个魔法时刻还没被发明出来。

两家的产品哲学也在分叉。Anthropic 的打法是捆绑加限制，模型和产品绑在一起卖，放开节奏自己握；OpenAI 哲学上更开放，到处铺接入，先看长出什么。Swyx 在和 Anthropic CPO Mike Krieger 的晚餐上提过一幕：桌上的人轮流说自己最担心什么，他选了生物安全，结果 Krieger 坐在那里，心里清楚自家代号 Mythos 的模型意味着什么，只回了句：真正要担心的是安全。

顺带一提估值端的疯狂：xAI 正在按 1.2 万亿美元的估值 IPO。Anthropic 去年还在为资本发愁，编码恰好踩中，模型恰好合适，执行又漂亮，现在成了全球最健康的公司之一。Jacob 的观察是，晚期公司现在每三个月就可能遇到一次生死级事件，向上向下都有可能。

你的下一个客户是机器人

Vercel CTO Malte Ubl 在 Swyx 的大会上给过一个数字：Vercel 管理后台的流量里，60% 是 bot,主要是编码智能体，人反而成了少数。

Swyx 给的对策很直接：产品如果没有 API,对智能体来说就等于不存在。顺手把 CLI 也做了。Netlify CEO Matt Biilmann 在推「智能体体验」这个概念，Swyx 的看法是，为智能体做的每件事，都是早就该为开发者做的事：好文档、无状态的一致 API、可被发现。现在只是多了一个非做不可的理由。

短期红利是 AEO,让聊天机器人愿意提你的名字。邮件服务 Resend 是个好案例，2023 年才成立，最近有调查统计 Claude 默认推荐哪家邮件服务，70% 的回答是 Resend。榜单只有三个位置，挤进去就是复利。配套动作是语义关联：写「配合某某工具一起用」的组合内容，这些会被收进语料。

但他提醒，这套玩法寿命大概三四年。等记忆和个性化成熟，推荐会跟着每个用户的上下文走，刷提及频率就没用了。他留了个思想实验：现在做一个新的 Supabase,怎么让智能体推荐你？这个问题暂时没有标准答案，谁先想清楚谁占便宜。

黑暗工厂：下一层疯狂

Swyx 最近反复讲「黑暗工厂」，这个词由他和 Simon Willison 推火。它有层级。

第一层，零人类写代码。五个月前他在 Cognition 第一次见到这种用法，当时觉得激进，现在看很合理。

下一层，零人类审查。代码直接合入，人连看都不看。现在几乎没人在做，OpenAI 在探索，听起来和当年的零人写代码一样疯。但这是唯一能规模化的路径，前提是把整个软件开发生命周期翻过来：更多测试，更多自动化验证，这些本来就是欠账。

解锁之后，软件产量会大到吓人，便宜到可以随手扔。他判断，数量会反过来帮质量：试错成本趋近于零，质量创新反而加速。很多人不舒服，因为大家习惯把数量等同于 slop。

2026 年做得好的人，是那些说「这事有没有我都会发生，我来把它掰向好的方向」的人。说「这就是 slop,我不参与」的犬儒，只会被甩在后面。

两个改口的观点

Swyx 主动交代了一次看走眼。去年他和 Braintrust CEO Ankur Goyal 做节目，对方说开源模型市场份额 5% 还在跌，他信了。现在他改口：份额在涨。公开基准上差距说不清，基准太容易刷；但 OpenRouter 上用户自由选择的用量数据里，开源模型实打实在涨，只是要按折扣做价格修正。

他强调别看行业均值，要分层：前 20% 的头部 agent lab 和后 80% 的普通套壳公司行为完全不同，头部在加速拥抱开源模型。Fireworks 和 Together 业绩凶猛，微调即服务这个去年被判死刑的生意活了过来，它就是开源模型市场的衍生品。工具链也在成熟，Thinking Machines 的 Tinker、Prime Intellect 都在把门槛打下来。

自研模型这条路也被验证了。Cognition 的 Composer 2 和 Cursor 的 SWE-1.6,在无补贴的模型切换器里被用户自由选进前五，这就是市场投票。打法被 Swyx 叫做「agent lab 剧本」：先用大厂的前沿模型起步，等负载和高质量数据攒够，再蒸馏出小模型自己跑，成本和延迟一起降。

定制芯片是另一条暗线。Cerebras、MatX 这些非 NVIDIA 玩家全被资本抢，推理速度能做到每秒数千 token,传统方案不到一百。Cognition 押了 Cerebras,OpenAI 也有合作。Swyx 之前是怀疑派，觉得快 2 倍没什么，现在改观：每 10 倍的推理速度都会解锁一种新用法，只是没人知道是什么。这个投资周期以年计，别急着下结论。

还有个有趣的猜测。Google 当年发布 Gemini 时报了 flash、pro、ultra 三个尺寸，ultra 至今没发。Swyx 猜它躺在地下室，一直给 flash 和 pro 当蒸馏老师。超过 10 万亿参数大模型的配给制，他认为是暂时现象，未来三五年更大的集群上线，配给会下移到下一阶段。

Jacob 也交了一份改口：RL 后训练。他过去认为，为质量做后训练没意义，大模型三个月后白送。现在他想通了：应用公司本来就把东西每三个月推倒重来，能力提升是同一件事。结果会过时，数据不会，留着再跑一遍就行。成本算下来，相当于雇四个工程师干三个月，只要它真是当下对客户最有效的那件事，就值。

Swyx 在结尾留了两个关键词：合成评分标准(synthetic rubrics)和 Dr. GRPO。指向同一个趋势：RL 正在从单轮走向几百轮的多轮训练，模型可以被定制到深得多的维度。

SaaS 的裂缝已经出现

基础模型会不会吃掉创业公司的品类？Swyx 分层回答。极小的公司不怕，最差结局是被 lab 收编，「那就当求职面试」。中型公司危险，LLM 基础设施已经开始整合，Langfuse 被 ClickHouse 收了。

真正被挤压的是低 NPS 的传统 SaaS。Swyx 用自己的公司做了实验：活动与赞助商管理 SaaS,一年 20 万美元，他估算花 2000 美元就能自建一个够用的版本。技术上不难，难的是把团队带上船。他是团队里最懂技术的人，也没法一个人拍板。

他描述了现在每家公司都在发生的内战。一派说，vibe coder 周末攒出个 80 分方案，烂摊子留给同事收拾；另一派说，你以为必要的东西其实不必要，忍一忍直接用自然语言跟智能体干活，生活会更好。两边都有道理，所以裂痕在扩大。

他的结论：会动手替换，「最多再拖一年，不会拖五年」。同时他看到一个空位：AI 原生的 system of record 还没出现，「AI 应用的 Firebase」这个位置空着，Convex 被反复提起，但答案还没来。

收尾时 Swyx 给了这期最值得抄走的一句话：2025 年是编码智能体之年，2026 年是编码智能体冲出笼子、去做其他所有事的一年。编码智能体继续赢，因为它们生产软件，而软件吃掉世界。过去四五个月最大的故事 OpenClaw,一个开源个人智能体，正是这股劲的预演，消费级智能体的冰山才露了个头。

他盯的下一个前沿是记忆与个性化，还有世界模型。一个冷知识：上下文长度是 LLM 里爬得最慢的指标，三年才从 4000 token 走到 100 万，Gemini 的百万上下文摆了两年，几乎没人用，真正的瓶颈在记忆。至于世界模型，他提醒别把它等同于机器人或游戏，真正的问题是，AI 到底懂不懂什么是桌子、什么是物质、什么是物理。他推荐李飞飞谈空间智能的文章：她可能还没给出答案，但她把问题问对了。他还打了个《心灵捕手》的比方：马特·达蒙演的威尔读遍群书，什么都知道，却什么都没经历过。顶级 LLM 的处境一模一样：全知，且未经世事。

最后是两个人留给听众的清单，明天就能开工：

  • API 自查：打开自家产品问一句，智能体调得动它吗？文档对 CLI 和 MCP 友好吗？没有 API,等于在智能体世界不存在。
  • 把 200 美元订阅当探索预算：Claude Code 或 Codex 的额度，补贴期不薅白不薅，每周固定跑一次新能力实验，别只拿它写周报代码。
  • 给公司的 SaaS 做个体检：列出 NPS 低、年费高的订阅，估算自建成本，先算账再动手。记得拉上团队，别一个人拍板。
  • 负载稳定的团队试试小模型：高频、低方差的活儿，蒸馏或微调一个开源小模型自己跑，Tinker 这类工具已经把门槛降了不少。
  • 心态上别当犬儒：这事发生不发生，跟谁的态度都没关系，能决定的是把它掰向哪个方向。
