《一个周末训出 GPT4All、狂揽 5 万 GitHub 星，Nomic AI 的算盘是给非结构化数据做 Excel》

先看一组数字。一家叫 Nomic AI 的创业公司，靠 Atlas 产品生成的数据地图在 Twitter 上刷屏，随后宣布拿到 1700 万美元投资；它的开源模型 GPT4All 在 GitHub 上涨到 5 万颗星，Discord 社区快 2.5 万人。

再看一个容易被忽略的事实：这个 5 万星的模型，是一个周末训出来的。做它的初衷，是给公司另一款产品打广告。

那款产品叫 Atlas，干的事情说出来有点朴素：帮人看数据。Redpoint 的 AI 播客《Unsupervised Learning》最近请到 Nomic 联合创始人兼 CTO 安德烈·穆利亚尔（Andriy Mulyar），他把整套逻辑讲得很直白：模型和训练流程都在快速变成标品，真正拉开差距的是数据策展，而这件事恰恰最难自动化。

从一场只有 40 人的聚会说起

安德烈 13 岁开始写代码，上大学时加入研究生物医学文本的 NLP 实验室，从那时起认定计算的机会在 AI。2019 年，他在机器学习顶会 NeurIPS 上认识了后来的联合创始人 Brandon。

那年 NeurIPS 大约一万人参会，全场的热门是图像，NLP 还在主流视野之外。大会的 NLP 线下聚会，只来了 40 个人。两人环顾四周，发现彼此是全场最年轻的，就这么聊上了。Brandon 刚出研究生院，正给一家创业公司招人，那家公司拿医疗文本训练大语言模型。安德烈直接加入，公司叫 Rad AI，产品是帮放射科医生自动生成报告摘要。

这段经历给了他一条受用至今的经验。做机器学习的人迟早会明白：花一个月改模型架构，提升常常比不上花一周清洗数据。问题在于，没人愿意盯着文本文件一条条看。这活无聊、累人，偏偏是整个流程里收益最大的环节。

2023 年 ChatGPT 引爆行业，一大批新入场的人才开始补这一课。安德烈和 Brandon 因为入场早，提前几年就把这笔账算清了。

Atlas：非结构化数据版的 Excel

安德烈对行业的判断是，机器学习流水线里的大部分环节都在变成标品：部署有现成方案，训练有 MosaicML 这类公司宣称全程自动化。剩下唯一啃不动的硬骨头，是数据策展。往模型里放什么、剔什么，直接决定模型的上限。喂进去垃圾，吐出来的就是垃圾。

Atlas 就是为这根硬骨头做的：一个非结构化数据集的交互式查看器。假设你手上有 6000 万份文档，想拿它们去训练模型，放哪些进去、剔哪些出来，是个大麻烦。Atlas 让你把这几千万份文档（马上要支持上亿份）扔进去，文本、图片、视频、音频都行，它按语义相似度自动聚类，画成一张能缩放、能点选的地图。没有机器学习背景的人，也能在上面完成过去需要 PhD 才能做的数据工作。

这张地图背后有个关键人物。一位纽约大学教授业余写了开源库 DeepScatter，能在浏览器里流畅渲染数十亿个数据点，Nomic 把他挖了过来。安德烈说，五年前这事做不成，浏览器技术没跟上。最早那批发表降维算法论文的研究者，十年前就有同样的想法，只是工具不成熟，只能作罢。往底层看，Atlas 的本质是“世界上最好的嵌入数据库，外加一个嵌入数据库查看器”。

谁在用它？两类人。一类拿数据喂机器学习模型；另一类手里攥着一大堆非结构化数据，完全不知道从哪下手。有风投机构把 deal 数据灌进去，生成一张当前项目流的脑图。安德烈给的类比很直接：Atlas 就是非结构化信息版的 Excel。有表格数据用 Excel，有文本、音视频、图片，用它。

机器学习那类用法是他们的初心，流程是个反复打磨的闭环。以 GPT4All 为例：训完模型，把每条输出连同模型自带的置信度分数放进 Atlas，画成热力图。哪片区域模型特别没把握，地图上直接看得见，然后删掉或强化那片区域对应的训练数据，再训。改数据，就是改模型。

调试幻觉是同一套逻辑。幻觉的来源，主要是训练数据里的虚假关联：模型见过太多真假输出混在一起的例子，就学会了在编造和实话之间自由切换。当年在 Rad AI，医疗场景里模型一本正经地编造，产品就不成立。团队当时的土办法，是人工翻数据，找到幻觉输出，反查对应的输入文档，再清理掉。Atlas 把这套流程搬到了地图上：找到一个坏例子，等于找到了一整类坏例子，因为语义相近的数据在地图上彼此挨着。

安德烈建议把 LLM 理解成“用数据编程的计算机”。想让它少幻觉，清理输入；想让它张口就编，往里塞烂数据就行；想让它动不动拒答，同样能用数据调出来。Atlas 卖的，就是对模型输入端的操控权。

生意模式倒是清晰。Atlas 主要做 B2B，按用量收费：存的数据越多付得越多，数据集上的协作者越多付得越多，后续还计划对“用客户数据直接生成模型”“生产环境级访问”这类功能单独收费。目前最打动客户的点，是 Atlas 能部署进企业现有的基础设施。大多数公司没有处理大规模非结构化数据的工具，最接近的方案是把 Parquet 文件丢进 Databricks 或 Snowflake 的集群，安德烈的评价是，那套东西对数据科学家不友好，Atlas 补的就是这个位置。

GPT4All：一个周末训出来的广告

2023 年 3 月，OpenAI 发布 GPT-4 技术报告，安德烈读完那份 PDF，注意到里面的表述：OpenAI 不会再对外开放模型。他觉得这触碰了机器学习的一条老传统：早在 2000 年代初，Journal of Machine Learning Research 就因为开放获取的问题从 Elsevier 独立出来，开放研究一直是这个领域的底色。于是 Nomic 决定自己训一个模型，既是回应，也顺便给 Atlas 做演示。

当时最好的模型全在 OpenAI 手里，只能调 API。安德烈的判断是，训大语言模型没那么神秘，他们有经验，正好当众证明一遍。现在回头看，一批 YC 孵化的公司已经在做 LLM 训练服务；3 月那会儿，多数人还觉得训练自己的大模型遥不可及，Nomic 恰好站在一个知道怎么做的位置上。

做法是蒸馏。收集几百万条 ChatGPT 的输入输出对，全部倒进 Atlas，把垃圾剔掉，压到三四十万条高质量样本。所谓垃圾，就是坏输入和坏输出，而在语义地图上，定位到一条就能顺藤摸瓜清掉一片。这套手法并不新鲜，深度学习时代最早的蒸馏论文，是辛顿 2015 年那篇师生蒸馏。安德烈的看法是，蒸馏就是众多训练手段里的一种：想让模型学会当助手，从更强的模型那里蒸馏很划算；想做别的方向，就得另想办法。

然后是训模型。一个周末，训完。真正的胜负手在发布环节。当时一位保加利亚开发者 Georgi Gerganov 正在做 GGML 库和 llama.cpp 项目，让大模型能在普通 CPU 上跑推理，那个项目当时还不到 1000 颗星。Nomic 直接 fork 了仓库，把自己的模型架构适配进去。用户拿到手的是一行命令，敲下去，终端里弹出聊天界面，一台本地版的 ChatGPT 就跑起来了。

效果夸张到什么程度？一台 2013 年的老电脑，没有独立显卡，只有 CPU 和少量内存，照样能跑。不用按每小时 10 美元租 GPU，不用订任何订阅服务。很多人此前默认，这种技术必须靠几百万美元的 GPU 集群伺候，GPT4All 一夜之间打破了这个认知，5 万颗星就是这么涨起来的。

至于拿 ChatGPT 的输出训模型是否违反 OpenAI 的服务条款，安德烈不回避：GPT4All 用了非商业许可证，把该注意的地方都注意到了。但他也直说，如今 Hugging Face 上排名靠前的开源模型，几乎都在用同一套蒸馏流程，OpenAI 实际上管不住这件事。

Atlas 收钱，GPT4All 免费，两条线怎么平衡？安德烈的答案很实在：开源那一侧绝不塞广告、不塞付费功能，社区最反感这个；商业那一侧好好赚钱，因为正是 Atlas 的收入，养得起 GPT4All 的开发投入。两边互相供血，谁也别拖累谁。

装进游戏 NPC，装进老手机，再装进 MacBook

主持人提到，Llama 2 等开源模型接连发布，GPT4All 会不会被淹没？安德烈的回答没停在模型本身，他抛出了这次走红给公司上的一课：软件最重要的品质，是对非技术人群足够易用。装半小时依赖才能跑起来的东西，注定只有极客碰。他给 Atlas 定的目标，是简单到“你的祖母也能上手操作喂给 LLM 的数据”。

易用性打开了一些以前根本不存在的场景。最典型的是电子游戏。以前想给游戏 NPC 接上大模型，只能走第三方 API，等于玩家每玩一次、开发商付一次钱，这功能基本没法上。现在模型直接打包进游戏，在玩家本地机器上跑，边际成本归零。Discord 里已经出现了整款游戏把 GPT4All 嵌进 NPC 的作品，每个 NPC 挂不同的提示词，全在本地运行。

另一个高频场景是开发省钱。安德烈说，几乎每天都有开发者来 Discord 报告同一件事：生产环境用的是更大的模型，但过去三个月的开发迭代全用 GPT4All，因为便宜，也不占额外资源。

接下来 Nomic 要拆的是硬件门槛。目前大多数模型只能跑在 NVIDIA 显卡上，他们接入了开放标准 Vulkan，让模型能跑在 AMD、高通、三星的 GPU 上。GPT4All 官网还维护着一份精简模型清单，专门收录能在低资源设备上跑的型号。安德烈的目标更极端：老手机也应该原生跑大模型，不依赖任何外部服务器和 API。不能让这项技术攥在少数硬件厂商和少数公司手里。

聊到设备，绕不开苹果。安德烈的判断是，苹果历史上向来不是第一个出手的，但出手时往往做得最好，这次大概率也一样。Nomic 内部在 Apple Silicon 芯片上做过大量底层优化工作，他的评价是“极其出色”。

我能想到的是，几年之后，你收到一台 MacBook，里面已经预装了一个 LLM，苹果针对自家芯片把它调到了极致。

他的依据是苹果的赌注方向：从芯片开始自研，押的正是“计算机上的大多数操作，都会先经过 AI 模型再返回给用户”的未来。顺带一提，安德烈用了一辈子 ThinkPad，去年换了 Mac。

Agent 被高估了，开源会赢

开源与闭源的走向，主持人抛出了当下最典型的对立：一派认为 AI 该关起门来搞，理由是安全；另一派坚定站开源。安德烈的判断分两层。OpenAI、Cohere、Anthropic，加上融了大钱的欧洲公司 Mistral，如果模型开箱即用的质量够高，确实能说服企业花几百万美元买省心。但大多数做 AI 应用的公司，最终会选择自己跑模型：数据不过第三方 API，在开源模型上做定制和微调。医疗行业是现成的例子：医疗 AI 公司只有两条路，自己训模型，或者跟 OpenAI 签一份昂贵的协议，除了巨头医疗公司，多数人选了前者。

他还给了个大胆的判断：现在各家推理 API 的价格是故意压低的，为的是抢占应用入口。按 GPT-4 这个量级的模型算，长期看这种定价撑不住。

把镜头拉远看工具链。Hugging Face 在托管模型和数据集上干得漂亮，基准和指标也最全。真正的重灾区是部署：选项太多，踩坑的方式也太多，有人为一个每小时才来一次的请求，付着每小时 3 美元的 GPU 账单。再往上是做 LLM 防火墙的公司，防止员工把敏感数据发给模型，还有做评测的。安德烈觉得，这一层就是过去几年的 MLOps 换了层 LLM 皮肤。真正缺人的是数据环节，他自己算一个，另一家是西班牙的 Argilla。他的建议很硬：不花时间跟数据相处，就是在烧钱，几千美元的 GPU 账单喂进去烂数据，出来的还是烂结果。

问他看好哪家公司，他给了个不同寻常的答案：别盯着产品看，去看创始人的背景和应变能力，这个阶段真正较劲的，是创始人能不能跟着环境快速调整。方向上他倒说得明确：大机构的通用模型不会适配所有场景，企业自建模型的需求会一直在。GPT4All 适合断网环境下的边缘设备，Character.AI 那种每小时处理百万级请求的业务，需要的又是另一套服务基础设施。怎么建，要跟怎么用对齐，不然钱都喂了 GPU。

快速问答环节，主持人问当前 AI 领域什么最被高估，安德烈没客气：Agent。

每次去聚会，所有人都在聊 Agent。但平均下来，这些东西就是不好使。错误会累积。你随便找个线上 Agent 产品，让它订机票，我赌 100 美元，它订不成。

他连定义都看不顺眼，说听到过一个版本：一串喂给 LLM 的输入输出，中间没有人看结果。至于 AGI，他的态度更冷：靠求解大规模优化问题这套深度学习范式，外挂多少 Agent 都到不了 AGI，需要根本性的范式转移。他还补了一句，在吓唬公众这件事上，很多公司干得相当出色。变化倒是已经在发生，Nomic 的工程师每天用模型干活，说它们是不会嘲笑你问蠢问题的小黄鸭。

监管话题，他的态度务实：监管的定义就是让事情慢下来，这本身无所谓好坏。用 LLM 批量生产宣传内容、影响 2024 年选举的边际成本，已经低到历史最低点，这种事确实该管。但要警惕另一面，有公司在借监管挖护城河，把新玩家挡在门外。他真正操心的是许可证问题：软件许可证体系和模型权重的发布方式根本不匹配，运行模型的软件和模型权重是两个完全不同的东西，该给后者设计什么样的许可证，整个行业还没想清楚，Hugging Face 自定义许可证算是迈出的头几步。

明天就能用上的三件事

这期播客信息量不小，挑三件明天就能用的：

  • 训模型或微调之前，先花一周时间看数据。安德烈在 Rad AI 的经验是，一周清洗数据带来的提升，大概率超过一个月改模型结构。预算有限的话，钱先花在数据上。
  • 调试幻觉，从输出反查输入。把出错的那批输出收集起来，回溯它们共同的训练数据来源。语义相近的坏数据往往成片出现，删一片比删一条有用。
  • 开发迭代用小模型，生产环境再上大模型。本地跑一个开源模型做日常开发和测试，不花钱、不联网、数据不出机器，逻辑跑通了再切大模型 API。Nomic 的 Discord 里一堆开发者就是这么干的。

最后补一句联系方式：Nomic 的 Twitter 账号是 nomic_ai，官网 nomic.ai。安德烈说，他们真的会回邮件。
