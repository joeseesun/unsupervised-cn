《三年500倍、年化破10亿美元，Modal CEO 把算力生意的底牌讲透了》

英伟达 GTC 大会上，Modal 的 CEO Erik Bernhardsson 转了一圈，把现场比作「露天毒品市场，只不过交易的是 GPU」。走两步就有人凑上来问你要不要卡，酒店大堂里互换联系方式，其中一笔生意最后靠销售副总裁的表亲打高尔夫认识的人牵线才谈成。

这个画面来自红点创投播客 Unsupervised Learning 的最新一期。主持换成了红点合伙人 Patrick Chase，嘉宾 Erik 是第二次上节目。他是瑞典人，创办 Modal 前在理财平台 Betterment 做了七年 CTO。Modal 2021 年底写下第一行代码，最早的产品是个 serverless 函数平台。三年过去，年化收入从 A 轮时的 200 万美元涨破 10 亿美元，涨了大约 500 倍。单拎沙箱（Sandbox）产品，年化 3 亿美元，占公司收入三分之一；LLM 推理也占三分之一。

这一期聊了 GPU 到底怎么买、沙箱怎么押中的、推理的护城河在哪、agent 时代写代码变成了什么样。挑重点讲。

找卡靠 WhatsApp 群和酒店大堂

很多人以为 AI 公司缺卡缺到买不到。Erik 的说法是，产能其实找得到，代价是接受更高的价格、更长的租约。Modal 现在每周谈两到三笔算力合同，接入了 25 家云，还在继续加。聚合需求、统一管理这些分散产能，正是 Modal 商业模式的核心。

为什么市场这么碎？因为算力离「同质化商品」很远，结构上很难变成交易所里的标准化合约。磁盘、网络、CPU、内存配置各不相同，地理位置散落全球，美国、欧洲、印尼都有卡。Erik 觉得这种混乱状态会持续很久。

「去年去 GTC，就像露天毒品市场，只不过交易的是 GPU。到处找人、换号码，还有大量深夜的 WhatsApp 群。」

更麻烦的是可靠性。不少卡来自前矿场，从没按 7x24 小时的标准运营过，说挂就挂。Modal 的做法是把这堆异构产能聚合起来，节点挂了自动移出轮换，很多情况下自动开工单派人去查。

市面上提供 GPU 价格数据的公司有用吗？Erik 说中等有用，价值在人脉，不在报价，他们靠这类公司认识新云厂商。至于公开报价他不太信，Modal 内部成交价和公开价格对不上。

沙箱：几天写出的原型，涨了近1000倍

Modal 的产品路径值得细看。2021 年底起步做 serverless 函数，本想覆盖数据和机器学习的广泛场景。结果 ChatGPT 和 Stable Diffusion 在 2022 年底前后先后爆了，Modal 恰好特别适合托管 Stable Diffusion 应用，第一年的增长几乎全靠它。

2023 年，他们注意到有人拿 LLM 生成代码，判断这些代码需要一个隔离环境来跑，而 Modal 底层设施天然合适，于是推出沙箱。原型只花了几天。当时没立刻爆，到 2025 年模型写代码能力上来，沙箱开始爆炸式增长，涨了将近 1000 倍，系统为了扛住规模重写了五次。

Erik 把沙箱称为一次「不对称下注」：下行很小，原型几天就能搭出来；上行巨大，赌中了就是今天的局面。他坦白说，现在还没有第二个同等爆发力的东西在酝酿，但有几个大赌注：低延迟的语音对语音和实时视频，要重新思考全球算力调度，相当于给推理建一张 CDN；还有训练，中等规模模型和强化学习的训练被他认为是被低估的市场；再往上是支持完整操作系统，macOS、Windows、安卓都跑起来。他顺便吐了个槽：2026 年了语音助手还是这么烂，家里的 Google Home 十句听不懂八句，最后还是去问 ChatGPT。

LLM 推理的产品化则晚得多。2025 年初 DeepSeek 出来，第一个真正能打的中国开源模型，Erik 的原话是「管他的，必须进场」，随即组建了二三十人的团队专职做推理性能优化。18 个月下来，LLM 推理占到了收入的三分之一。

支撑这一切的是早年下的苦功夫。Modal 自研了文件系统、容器运行时和调度器，不用 Kubernetes 和 Docker，隔离用 Google 的 gVisor，最近部分场景引入 KVM。回报是冷启动极快：自研文件系统让容器加载飞快，CPU 和 GPU 快照能把数据从磁盘或网络直接灌进 GPU，几秒钟拉起大模型；过去半年还搭了一套基于 RDMA 的节点间点对点拷贝系统。

Erik 的总结是，这个市场一大块 alpha，就来自不怕做难的事。路走了远一点，但攒出了很难复制的技术。

卖 token 是逐底竞争，平台才是护城河

推理市场怎么赢？Erik 的判断分两层。

第一层，纯卖 token 是逐底竞争。OpenRouter 这类聚合层已经在压榨底层供应商的利润。靠最新 kernel、更高效的 KV cache 保持领先当然要做，但这些技巧迟早会扩散，护城河不持久。

第二层，持久的差异化在平台。沙箱、强化学习、微调、批处理、各种模型的部署，客户不想买单技小马，想买一整套工具。和不少闭门造车的推理供应商不同，Modal 还积极参与 vLLM 等开源推理引擎的开发。Erik 的逻辑很直接：Modal 的 alpha 在基础设施层，自动伸缩、调度这些自研系统才是命根子，推理引擎开源，反而能借全社区的力。

芯片的选择上，英伟达仍是王者，需求远超其他所有厂商，Modal 正在激进扩容 Blackwell，主要是 GB 系列。但 H100 至今仍是平台上最常见的卡，大量生产级负载跑在 Hopper 上。语音、音频转写、语音合成、制药的分子模拟和序列比对，这些负载用 Hopper 甚至 L40S、RTX Pro 6000 反而更省成本。AMD、Trainium、TPU 也开始能看了。

模型配卡有没有黑科技？Erik 说经验法则简单粗暴：基本是内存约束，选能装下模型的最便宜那张卡，几乎适用于所有情况。最新的旗舰 LLM 需要整台 8 卡 B300 节点，因为参数就那么大。未来六个月 Modal 想做一件事：用户部署模型后，平台自动在多种 GPU 之间切换，保证每请求或每 token 的成本不变，把整体利用率抬上去。

模型会变小吗？Erik 押注继续变大。他的理解是，LLM 某种程度上是个粗糙的世界模型，像一张事实查询表，有多少内存，人们就会训多少参数。B300 的内存再多一点，Kimi K3 就会更大。

Agent 时代的软件工程：资深工程师冲在最前

Modal 的客户名单本身就是一张 AI 应用地图：Cognition 用沙箱跑强化学习的 rollout；Ramp 用它跑后台编码 agent，还把这个内部工具独立成了产品对外卖；Suno 和 Runway 跑生成音频视频；Decagon 拿它做语音和文字客服；DoorDash 跑内部 LLM 应用；一批生物制药公司做分子模拟和药物发现；1X 等机器人公司训练机器人模型；还有大量数据生成公司用沙箱跑环境和评测。

更值得琢磨的是「消费者变成 agent」这件事。Erik 说变化比他预期的小得多：agent 想要的东西和工程师一模一样，快反馈、清晰的报错、好的文档。当年为工程师体验建的东西，agent 直接受益。

但有几件事变了。第一，弃用功能变难了。agent 的训练数据里全是网上的旧代码，你从文档里删掉 API 等三个月没用，agent 照样生成调用旧接口的代码，Modal 不得不大幅拉长弃用窗口。第二，他们搭了自动化管道，让 LLM 不停地写 Modal 代码，验证能不能编译能不能跑，提前抓住 agent 容易犯的错。第三，他们在追踪一个指标：去问 Claude Code「我想部署这个模型」，全程不提 Modal，看它推荐哪家工具。Erik 的判断是，进了训练数据就等于有了粘性，软件在位者的权力变大了。有人说以后前端只用 React，因为 agent 写 React 最熟，就是这个逻辑。

Modal 内部，合入的代码大概 95% 由 agent 参与写成。反直觉的是采纳人群：他原以为初级工程师会用得最凶，结果几乎反过来，是资深工程师。agent 对他们像配了 10 个实习生，瓶颈从想法变成了打字速度。有资深工程师给 agent 一套完整实现 POSIX 标准的文件系统测试套件，让它写个新文件系统，三天交付。

工程流程也在跟着变，CI/CD 投入明显加大。Erik 提到听说 Anthropic 几天前宣布要迁离 GitHub，如果每天 commit 量再涨十倍，会撞上基础设施的根本限制。

那工程师会失业吗？他的答案：未来几年不会，基础设施的可靠性尾部风险仍需要人盯着。更长期看，工程师生产率每提高一次，需求反而上涨，编译器、高级语言、CI/CD，过去三四十年都是这个模式。短期新毕业生会难一些，长期他仍然鼓励孩子学计算机。

新云、S-1 和 12 个月后的卡价

聊到争议很大的新云（neo cloud），Erik 的态度是：商业模式没问题，但要看清本质。这些公司核心是融资工具，做的是硬资产租赁，增长极其烧钱，杠杆极高，股价随 GPU 价格剧烈波动很正常。好消息是客户合同锁定了，GPU 残值比预期高、寿命比预期长，还完债转卖还能赚一笔。但差异化很弱，长期不好说。

马斯克发推说新云都会死。Erik 直说这是扯淡，但承认马斯克点中了一个关键：SpaceX 资本成本低。看三家成功的超大规模云厂商，AWS、Azure、GCP，全都背靠现金流充沛的上市公司，做资本密集生意时日子好过得多。新云的资本成本高，增长就慢。

他更担心的是另一批人。市面上大量新实验室每家都正好融了 10 亿美元，然后去买卡。今天的 GPU 承诺通常只要付 30% 首付，10 亿现金能撬动 30 亿的卡。一年后要再付几亿，每个月都要付，这是隐性杠杆，全靠后续融资续命。一旦 VC 收手，就会出现二级市场，这批实验室转租、卖卡，或者干脆转型做新云。Erik 提到 Mistral 已经这么干了，看起来活得不错。他整体看好 AI，但习惯性盯着这类结构性风险。

12 个月后 GPU 租金涨还是跌？他押涨，而且是 48 小时内刚改的判断。起因是读了 Anthropic 的 S-1，让 agent 给他做了总结，发现这家公司基本是盈利的，盈利的公司没有任何理由放慢买卡。OpenAI 大概也是类似状态。这两家是市场上最大的两个买家，他们不停手，价格大概率往上走。

每家公司都要有自己的模型吗？Erik 的拆法很清楚：按收入加权，大部分 token 来自做过后训练的定制模型，Cognition 和 Cursor 都在自己训代码模型；按公司数量加权，大部分公司根本不需要自己做后训练。这个市场的关键问题是：后训练能不能做成标准化产品卖出去，做不成就沦为人力服务生意。

管理层面他也交了底。Modal 现在 150 个工程师，优先级是每天都要挣扎的事，就算有一千个甚至一万个工程师，想做的也做不完，CEO 的第一要务就是无情地分配资源，必要时叫停项目。复盘最大的错误，他说过去习惯串行做事，先做 A 解锁 B，现在学到的是很多时候 A 和 B 应该同时做。过去 12 个月 Modal 增长了 15 倍，他承认自己天性不够激进，是硬把自己练得更敢下注的。Modal 是他的 20 年项目，才走到第 5 年，第 10 到 20 年希望它更像一个集团，多条产品线，还有些疯狂的大赌注，他自己会继续管最高层的资源分配。

明天就能用上的几件事

三年前没人能猜到 Cursor、Suno、Cognition 会成为大公司，Erik 的态度是，三年后的爆款同样猜不到，但它们大概率会需要新的算力原语。听完这期，有几件事明天就能动手：

  • 选卡别纠结，先看模型多大，选能装下的最便宜那张，内存是第一约束，多数场景这就够了。
  • 用 agent 写代码，先花时间写测试套件，再放手让它写实现。资深工程师受益最大，经验越丰富越该把 agent 用满。
  • 做开发者工具的，尽早想办法进 agent 的推荐名单，训练数据就是新的分发渠道；同时把 API 弃用窗口拉长，你的用户里已经有大量 agent 在拿旧代码写代码。
  • 判断技术热点能不能押，用 RAG 当反面教材，Erik 自己说两年前押 RAG 今天看就是坏主意。多问一句：这个东西五年后还在吗？
  • 想试 Modal，终端里跑 pip install modal 就能玩起来，Erik 说他随时愿意和用户聊。
