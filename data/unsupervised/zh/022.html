《买一千块 GPU 反而更贵，Modal CEO 把 Serverless 推理这门生意讲透了》

在云上租 GPU,租一台能拿到折扣，租一千台，单价反而往上走。正常采购逻辑是量越大价越低，云市场现在完全反过来，想凑一批 H100,往往得多找几家供应商拼单。这是 Modal 联合创始人兼 CEO Erik Bernhardsson 在 Redpoint 播客 Unsupervised Learning 里给出的一手观察。

Erik 聊这个话题有资格。他在 Spotify 干了很多年，负责音乐推荐系统，顺手写了工作流引擎 Luigi 和近邻搜索库 Annoy,后者算是后来一大堆向量数据库的祖师爷。2020 年底他出来创办 Modal,做通用算力平台，Redpoint 投了这一轮，公司刚进 The Information 的 50 强初创名单。主持人 Jacob Effron 透露，当初背调时有人直接说，有机会写支票就赶紧写；还有人说，Erik 是自己见过最聪明的人之一。这期节目发布于 2023 年 10 月底，正是推理基础设施赛道最热的时候。

先自研文件系统，再谈开发者体验

Erik 最初想做的其实是一个更好的工作流引擎，毕竟 Luigi 就是他写的。研究一圈发现问题在更下面一层：工作流引擎再好，代码总得有地方跑，而「在云上跑代码」这件事本身就很折磨。

于是他往底层走，几个月后就意识到，想让容器加载得足够快，得自己写文件系统。当时周围人的反应是，你疯了，大家都用 Kubernetes 加 Docker,跟着用就行。他不肯，理由很直接：想要那个用户体验，就得把这些底层东西全部重写一遍。

这个用户体验，他给的定义是快反馈循环。判断一个工程团队的生产力，就看一件事：写完代码，多久能拿到反馈。传统流程是打包镜像、推上云、触发任务、再拉日志，一圈下来人已经去接了杯咖啡。他回忆早期 Hadoop 和 Spark 时代，跑个任务的标准动作就是启动，然后去喝咖啡，回来看结果。

Modal 做到的事，是把「写完代码」到「云端跑起来」压缩到几秒钟，快到让人感觉代码就跑在本地。Erik 又拿 Spotify 打比方：在 Spotify 点一首歌，歌其实从云端流过来的，但快到没人分得清。他想让跑代码也有这个体感。

顺着这个话题，主持人问他 GenAI 会不会改变开发体验。他的回答有点泼冷水：开发体验接下来最大的变化会来自云，GenAI 能改的可能就是补全更好用了。开发者生产力从来靠的都是一串 10% 的改进，叠在对数尺度上，最后变成几个数量级的差距。他估算 GenAI 能让工程师多产出 10% 到 30%,离 10 倍很远，但这些改进会一直叠加。

Serverless GPU 推理，撞上的第一个杀手场景

Erik 把开发者的选项摆了一遍。自己搭，得跟 CUDA 驱动版本搏斗好几天，而且 GPU 闲着也烧钱。用 Replicate 这类 API 服务，零定制，一旦要跑自己的模型或自定义工作流，又得回到原地。Modal 卡的是中间那段：自定义代码加 serverless,成本和体验一起解决。他自己吐槽，在 AWS 上撞墙的时间加起来大概有好几个人年。

有意思的是，他一开始并不看好模型部署这个方向。怀疑来自传统机器学习的经验：一家电商公司的典型场景，特征管道又长又复杂，模型本身反而小，一个 XGBoost 扔到 S3,写个简单服务去加载，完事。模型部署是整条链里最简单的一段，没什么差异化空间。

GenAI 把这个判断推翻了，他总结出三个变化：新模型必须跑在 GPU 上；规模一大成本爆炸，所以必须 serverless,按用量付费；而且没有那些复杂的特征管道，权重打包好直接拿来用。Stable Diffusion 就是一个纯计算问题，正好撞在 Modal 的强项上。公司做了一年半底层设施、还没什么客户的时候，生成式 AI 这个词甚至还没流行起来，结果几个月内大量做生成式应用的人自己找上门来。

现在 Modal 的营收大头来自音频、视频、图像的推理。语言模型反而少，原因很直白：今天最强的语言模型在 OpenAI 的 API 后面，自己部署很难追上那个性能。Erik 判断长期看钱都会在推理上，微调和训练也在做，但推理是绝对主力。

两个客户案例。Substack 用 Whisper 给播客做转写和内容描述，把音频切成小块并行处理，很快吃掉大量音频。Suno 做音乐生成，输入一句想要德国嘻哈配邦戈鼓，模型直接生成，用的是他们自研模型。除此之外还有计算生物、3D 渲染、网页爬取，但 GenAI 目前是压倒性的第一大场景。Erik 强调 Modal 仍是通用平台，长期想做的是取代 Kubernetes 的那个东西，serverless GPU 推理只是第一个被验证的场景。

这门生意现在有多热，主持人补了背景：Together AI 刚拿了 Kleiner Perkins 的钱，还传出 Emergence 跟进，Replicate、Anyscale、Fireworks 都在融资。Jacob 认为 Modal 的差异在于它不只是托管模型，数据转换、自定义逻辑、推理可以串成一条完整管道，这种端到端能力给未来留出了叠加高毛利产品的空间。

GPU 市场越买越贵的怪现状

回到开头那笔 GPU 的账。Erik 确认，新闻里说的 A100 难买是真的，而且云市场的定价逻辑拧着来：要的量越大，单价越高，或者干脆让你去别家凑。

但他觉得这事被夸大了。大家盯着 H100 抢，反而把 A100 释放出来了，而 A100 对大多数场景性价比更好。Modal 自己的主力卡是 A10,性能不算顶级，但每块钱买到的算力很适合推理，这类卡在好几家云厂商那里都不难拿到。代价是 Modal 得玩调度把戏：他们做了多区域支持，一天之内不同时段，有时去加拿大拿卡，有时去欧洲，有时能用上 us-east-1。他的希望是 GPU 价格迟早回归正常，产能会多起来，眼下确实有点乱，只是没新闻写的那么夸张。

至于推理成本会不会一路降下去，Erik 的答案带着点经济学味道。GPU 每年都在变快，软件优化也在挤出性能，但潜在需求太大了，把东西变便宜，总用量可能反而涨上去。

「我们离效率前沿还远得很。」

顺带说一个他没说完的愿望：Modal 的用户其实对用什么卡不太挑，他反而嫌让用户自己选 GPU 这个负担太重。A10、T4、L4、A40、A100、H100,型号一大堆，他想做的是自动选卡，用户只说一句要最低延迟还是最低成本。类比 CPU,现在没人在乎云端 CPU 是 3.2 还是 3.6 GHz,GPU 迟早走到这一天，只是还需要时间。

云的未来：算力寡头加体验层

Erik 有个观察：软件工程师可能是唯一还没把工作流搬上云的职业。

「你去牙医那里看看，他们的整套工作流都搬上云了。随便挑一个职业，所有事情都发生在云上，只有软件工程例外。」

裂缝出在本地和云端之间。拿 AWS Lambda 说，它没有像样的 mock 框架，想在本地测，就得把 Lambda 本身模拟一遍。Erik 的思路更彻底：既然模拟云很别扭，那就让云变成临时的，比如在云端起一个只活几秒钟的数据库，跑完测试就销毁。把云拉进本地的开发循环里，本地和云就是同一个环境，换环境、部署这些痛苦全部消失。

对云市场的长期格局，他看好的是少数几家超大规模厂商，数据中心和底层算力拼的是资本和规模，长期只会剩下寡头。他还替 AWS 说了句话：大家都说纯算力是商品生意，得往上做软件才有出路，实际上 AWS 光靠算力利润就好得惊人。他怀疑 AWS 根本不在乎开发者体验，人家有 15 年时间改善，没做。

所以他的预测是两层结构：底下是稳定的算力寡头，上面是一批聚焦具体工作流、把开发者体验做透的服务。AWS 得同时服务所有人，做透很难；上层服务只需要盯一类工作流，Snowflake 和 Vercel 是先例，Modal 想做数据团队的那一层。这是他几年前那篇讲云市场洗牌的文章《Storm in the stratosphere》的核心论点，这几年基本应验了。

这波 AI 还带来两个插曲。一个是 CoreWeave 凭空冒出来，成了家像样的云厂商。另一个是 Oracle 复活，Modal 自己就在用 Oracle Cloud,体验不错。Erik 分析，Oracle 占了个便宜：AWS 和谷歌都在自研芯片跟 NVIDIA 较劲，Oracle 立场中立，跟 NVIDIA 关系好，想拿 H100 那里相对好拿。

至于 NVIDIA 的垄断，Erik 给了个诚实的答案：他喊了五年十年，说 NVIDIA 明年就会遇到竞争，年年落空。他梦想的世界里有多个 GPU 厂商，AMD 起来，谷歌 TPU 生态成熟，AWS 把 Inferentia 和 Trainium 的 PyTorch 支持做好。他相信总会发生，只是比所有人想的都慢。

向量数据库、AI 音乐和 Transformer 吐槽

模型层的开源与闭源，他的判断是：历史上机器学习研究一直是开放的，几万名研究者共享成果，这两年收缩了，但会回归。OpenAI 靠砸几十亿美元买 H100 加挖人建立领先，但他怀疑边际收益在递减，Yann LeCun 那些开源会赢的论点有道理。另外，更聪明的模型架构带来的收益，可能比堆卡大得多。开源和闭源的差距会持续缩小。

向量数据库这段是他的老本行。2008 年前后他在 Spotify 就用向量做音乐推荐，自己用 C++ 写了个向量检索库，就是后来开源的 Annoy。当时他找 VC 聊过创业，觉得太早，放弃了。2021 到 2022 年，开源向量数据库从几乎没有变成 25 家创业公司扎堆。

他的判断有两层。短期看，大家把向量数据库塞进传统数据库的壳里，这符合新技术出现时的惯性。长期看，向量是组织信息的一种全新方式，十年后的向量数据库会长得完全不像今天的数据库，甚至输入端可能就是文本和图片，嵌入模型直接长在里面。

AI 音乐部分跟他出身有关。他说音乐是最纯粹的艺术形式，几乎没有元数据，一幅画你得知道画家的故事，音乐就是波形进脑子，好听或者不好听。所以他会把音乐选成未来几年 AI 生成内容渗透最快的领域，先是好制作人用好工具，纯 AI 作品随后就到。他还给 Spotify 出了个狠主意：版税支出那么大，能不能用自动生成的音乐替代一部分？他自己也承认这想法疯狂，因为音乐有社交属性，你得知道朋友听的是同一首歌，这事 AI 替代不了。Jacob 顺着补了个场景：也许会出现一个 GenAI 音乐社交网络，几个人合作写歌，互相改编转发。Erik 补了一句，音乐历来是新技术的第一批载体，乔布斯讲过这个观察。

快问快答里有个技术圈会喜欢的答案。问他 AI 里什么被高估了，他说是 Transformer。理由是，大家似乎把「学习世界模型」和「语言模型」混在一起了，语言模型更像是在读文字。他还补了句自嘲，Transformer 论文发表那阵子他刚好不追机器学习研究了，要是大家换个新架构，他正好从头学一遍。主持人在旁边打趣，Transformer 推理成本高，对他的生意明明是好事。

两条教训，四件明天能做的事

Erik 复盘创业第一年最大的错误：他跑去大公司，劝人把 Kubernetes 和内部数据平台拆掉换 Modal。让一家公司替换在用的技术，比让一家公司从零采用新技术难得多。想通这一点后，Modal 转向服务那些从零开始搭 AI 能力的团队，顺多了。

他还分享了卖 AI 基础设施的一个观察：企业里平台团队和干活的 AI 团队说的完全是两套话。AI 团队抱怨平台烂，什么都上不了生产；平台团队自豪地说系统很好，写点 YAML、跑五条命令就能上线。卖东西得同时说服这两拨人。

最后是可以直接用的几条：

  • 算 GPU 成本时，先分清训练还是推理。推理场景别无脑追 H100,A100 甚至 A10 这类卡性价比往往更好，而且好买。
  • 能用 serverless 按用量付费就别自己囤卡。新应用流量不可测，按用量付费意味着没流量时成本接近零，爆量时有人替你扩容。
  • 评估工程团队效率，盯反馈循环时长，从改代码到看到结果要多久。这个数字比代码行数诚实得多。
  • 卖新技术产品，优先找从零开始的团队，别把说服成本花在替换决策上。

想自己试的话，modal.com 就能上手，Erik 的 Twitter 是 bernhardsson。连 Redpoint 的投资人都在投资前一年用 Modal 写爬 Hacker News 的脚本，评价是写 Python 不用管基础设施，跑就完了。
