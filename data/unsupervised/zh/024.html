《OpenAI 五天宫斗复盘：微软赢麻了，创业公司该连夜写应急预案》

2023年11月17日，太平洋时间周五中午12点半，OpenAI 董事会一纸声明，开掉了全世界曝光度最高的 AI 公司 CEO 山姆·奥特曼，联合创始人兼总裁格雷格·布罗克曼当场辞职。接下来五天，这家770人的公司里95%的员工联名逼宫，微软 CEO 纳德拉先官宣把两人招进麾下，隔天又改口说“就算回 OpenAI 也算跟微软合作”。红点创投的播客 Unsupervised Learning 紧急加更一期，请来福布斯记者 Alex Konrad，以及前 GitHub CTO、红点合伙人、AI 编程公司 Poolside 创始人 Jason Warner，把这出大戏从头拆了一遍。

录制时大结局还没揭晓，但这期节目的价值恰恰在这里：它记下了行业里最懂行的一批人，在信息残缺的当下如何判断局势、如何调整自己的生意。下面按重点一条条说。

先补时间线：一部全世界都在追的剧

周五收盘前后，董事会宣布开除奥特曼，理由含糊。布罗克曼辞职。之后风向换了四次：

  • 首席科学家伊利亚·苏茨克维本是投赞成票的董事会成员，周日发推倒戈，宣布不再支持董事会的决定。
  • 周日，纳德拉宣布奥特曼和布罗克曼将加入微软，领导一个新的 AI 研究部门。
  • 紧接着，95%的 OpenAI 员工联名：董事会不下台，我们就集体辞职。
  • 纳德拉上电视改口：两人是不是微软员工不重要，反正会跟微软合作。

主持人 Jacob Effron 的总结是“世界上最不好笑的情景喜剧”。Jason 补了个细节：他在给妻子直播剧情，妻子回了一句“这是某部剧的新一季吧？现在又出来个新角色叫 Emmett”。这个新角色是 Twitch 联合创始人 Emmett Shear，董事会一度任命他当临时 CEO，而此前被推上临时 CEO 位置的米拉·穆拉蒂，最后也站到了奥特曼这边。流传过的候选人还有前 GitHub CEO Nat Friedman 和 Scale AI 创始人 Alexandr Wang。Jason 觉得 Nat 的名字最奇怪：如果开除奥特曼的理由是“他走得太快”，找一个以快著称的人接盘，逻辑上讲不通。

Alex 还提供了一个观察：过去的丑闻，WeWork 也好，Uber 也好，都只烧到一家公司，别的领域可以撇清关系。这次整个科技圈都在追，他半开玩笑说，大概因为《继承之战》完结了，大家需要新的一季。另外别忘了，这一切发生在 OpenAI 首届开发者大会结束才一周半的时候，当时社区一片叫好，反差大到没人反应得过来。

创业公司的账本：换掉 GPT，成本直接翻倍

这出戏对用 API 的人意味着什么？先看数据。Retool 调研过一批企业，超过80%表示主力模型就是 OpenAI。逻辑很简单：先拿最强的 GPT-4 验证场景跑不跑得通，开源模型、自建方案以后再说。结果就是几乎所有人都挂在 OpenAI 一棵树上。周五下午，大家突然发现树上还拴着别人。

Alex 第一时间找了一圈创始人收反应，答案两极。有人放话“在 GPT 上创业已死”。另一位创始人 Tomas Prieg（公司叫 Alembic，跟 Alex 是在推特上认识的）算了笔细账：从 GPT 迁到开源模型 Llama，成本大约翻倍，光服务器请求每小时就要8美元，规模一大就是真金白银。Jacob 补充，大量企业刚把基于 GPT 的功能推给客户，那个周末都坐在那儿发懵：线上这个功能下周还在不在？

推特上一堆人嘲讽“居然有人把鸡蛋放一个篮子里”。Jason 的回应很扎心：说这话的都是没运营过大规模系统的键盘教练。现实里大家就是只用 OpenAI，因为它最快、最强、比自己部署还便宜。他拿云计算行业打比方：人人都吹混合云，实际上混合云从来就不是一个真东西。

但 Jason 给在营公司的建议毫不含糊：

如果你在经营一门真实的生意，就必须马上做应急预案。哪怕方案只是“把微软托管的版本当备胎”，你也得有方案。拿不出方案，你就没在干自己的本职工作。

还有个被反复讨论的问题：OpenAI 背后有微软兜底，怕什么？别忘了那个周末 ChatGPT 已经对部分用户宕机了。Jason 的判断是，兜底这个词在真出事的时候值多少钱，没人验证过，不能拿公司的命去赌。

微软赢麻了？先看看别家在干嘛

这段是 Jason 情绪最激烈的部分。微软在这件事上处处显得漂亮，其他所有超大规模云厂商都显得很糟糕。纳德拉反应快、动作果断，直接从微软研究院调人组队。Google 呢？Sundar 呢？亚马逊呢？甲骨文在干嘛？全程静音。

唯一出来刷存在感的是 Salesforce 的贝尼奥夫，在推特上喊话 OpenAI 员工：来我们这儿，工资随便匹配。结果一位员工回怼：我不觉得一家做 Tableau 的公司能造出 AGI。Jason 倒是给贝尼奥夫记了一功：至少人家出场了。

为什么其他大厂出不来？Jason 的诊断指向组织结构：聪明人从来不缺，缺的是允许这种速度存在的组织结构。他讽刺某些大厂“内部四支团队在造模型，总有一支会赢”，然后补刀：三年后等这批高管全被炒了，回头再看吧。他甚至放话，照这个势头，微软五年后可能是除美国政府之外世界上最重要的实体。

Jason 在微软收购 GitHub 后当了多年 CTO，他讲了段往事：当年 CEO Nat Friedman 坚持不整合，GitHub 继续用 Google 的 G Suite 和 Slack，保持独立。后来微软还是强行推整合，GitHub 就变了味。所以在 Jason 眼里，一个独立的 OpenAI 加上紧密合作关系，比把团队吞进微软内部更值钱。纳德拉自己也懂这一点，100亿美元投进去没要治理结构，这周末肯定要在董事会层面被问个明白。

还有个细节很有画面感：微软宣布招人的消息一出，微软 .NET 部门有员工发推：“等等，我们不是没有 headcount 吗？”

董事会的公关灾难：两种解释，剃刀选了乱的那种

Alex 提供了媒体视角的拆解，切入点很专业：董事会通常没有自己的公关团队，用的就是公司公关部，而公司公关部效忠的是 CEO。OpenAI 董事会成员（比如 Quora CEO Adam D'Angelo）都是聪明人，但没有一个干过危机公关。Alex 回忆自己读到第一份声明时的反应，当时他在欧洲倒时差，脑子里只有一个念头：这种话不能写进新闻稿。

他把可能性归成两种：要么真出了大事，严重到董事会宁可被全网骂几天也要捂住；要么就是他们完全没料到反弹，那边彻底乱了。奥卡姆剃刀指向后者。证据链也很清楚：周五的声明措辞惊人，周六的声明开始改口，内部信再改一次。公关第一原则就是开了盒子就得给足后续，给不了就别开。

Jason 从另一个角度补了一刀：布罗克曼辞职这个动作本身就是信号。他是总裁，如果真有“惊天动地”的理由，董事会必须告知他细节；他选择辞职站队奥特曼，说明那个理由没严重到那个份上。伊利亚周末倒戈同理：如果真是“世界末日级”的问题，他不该改主意。

由此引出这期播客里分量最重的观点。Jason 说这事让 EA（有效利他主义）运动很难看，他对此“挺高兴”，因为行业需要的是务实的成年人对话，少来科幻式的恐慌叙事。但代价是狼来了效应：伊利亚在 GPT-2 那会儿就拉响过一次警报，这次又来一次。第三次他喊“我们造出了神”，还有谁信？真到那一天怎么办？另外 Jason 专门把火力对准了公司结构：非营利身份、董事会构成、激励怎么对齐，这才是政府和企业该认真讨论的事。

赢家输家名单，和奥特曼的回归剧本

Jacob 的角度更宏观：很多人本来担心 AI 的价值最终都归云巨头，微软、亚马逊、Google、Databricks、Snowflake 成为大家默认的采购入口。OpenAI 恰恰是那个反例，一家全新公司让大家愿意绕开云厂商直接下单。一个独立的 OpenAI 活着，等于给所有创业公司保住了“新公司也能吃下大市场”的先例。Jason 的版本更狠：不管结局如何，这几天对创业公司都是好事，因为它往一个原本以为尘埃落定的局面里重新注入了不确定性，不确定性就是机会。

录制时大家都押注奥特曼回归，主持人中途还假装插播“我刚刷了推特，Sam 回来了”，吓了大家一跳。在这个前提下，几位嘉宾的输赢判断：

  • 微软：表面大赢家，但 Alex 强调，如果能按个按钮让这一切没发生过，纳德拉会按的。微软要的是稳定和可预期，这场戏是巨大的干扰，而且纳德拉本人讨厌接受采访，电视上那张脸写满了不情愿。
  • 奥特曼本人：Jason 的判断是“他手里攥着每一张牌”，员工、舆论、微软三方都站在他这边。
  • Anthropic 和所有 OpenAI 的直接竞品：Perplexity、ElevenLabs、Ideogram，凡是和 OpenAI 某条产品线撞车的，都分到了顺风。
  • 开源阵营：Mistral 这类公司应该受益，行业等一个“试试 GPT 之外的东西”的契机很久了。模型切换、微调工具这类 AI 基础设施公司也跟着沾光。
  • Databricks 这类数据平台：不用发声，只要对企业客户足够主动，就能趁机多拿份额。
  • 输家：除了 OpenAI 董事会，就是其他沉默的云巨头，输在“看起来没人掌舵”。

Jason 还抛了个阴谋论：如果奥特曼回归而伊利亚离开，谁签下伊利亚谁赢，尤其如果那是马斯克和 Grok。他自己补了一句：反正我认识的人里没谁把 Grok 当回事。对开源模型公司，他还有段掏心窝的话：

搞清楚你怎么赚钱。拜托。你们的训练成本高得吓人。模型本身不是产品，它不是产品。想想怎么赚企业的钱。

回归剧本也聊了。Jason 给出的清单很经典：先稳住基本盘，企业客户、微软雷德蒙德、内部员工三头跑；接下来一段时间少露面，别再满世界见领导人（出事前一周他还在 APEC 峰会上社交，据说还在接触主权基金）；最后把投资人的新一轮员工股回购谈妥，别让员工吃亏。至于几天里最让嘉宾们下巴掉下来的时刻：Jason 选的是“董事会宣布和奥特曼谈判，谈崩了”那一刻；Alex 选的是“微软官宣招人、然后又不算数”那一刻，他原话是“现在你们随便说什么我都信了”。还有一位印度网友的推文被 Alex 转述，可能是全场最清醒的声音：“你们能不能建个 WhatsApp 群，商量好了直接告诉我们结局？”99%的普通人不在乎剧情，只关心自己的产品明天还能不能跑在 OpenAI 上。

后记：节目录完几个小时后，OpenAI 就官宣了奥特曼回归，董事会重组，Bret Taylor 出任新主席。嘉宾们押的注，全中。

明天就能用的三件事

这期播客信息量很大，拆到个人和企业层面，能马上执行的其实就三条：

第一，今天就写应急预案。只要你的业务跑在 OpenAI API 上且已经有真实客户，就按 Jason 说的办：哪怕方案只是切换到微软托管版本，也要写下来、测一遍。顺手把换模型的成本算清楚，像 Alembic 那样算到每小时服务器多少钱，别等出事那天才发现迁移要花两个月。

第二，向你的模型供应商提治理问题。董事会构成、股权结构、谁有权关停服务、出事时的赔偿条款。企业客户接下来都会问这些问题，先问的人拿到的答案和承诺就多。

第三，别把“多模型”停在嘴上。推特上的键盘教练会说“谁会只用一个模型”，现实是大多数人只用一个。真正的多模型能力要靠演练：每季度挑一个非核心功能，真的切到开源模型上跑两周，把坑踩在自己的地盘里。

最后借用节目里那句玩笑收尾：幸好这些破事发生在 GPT-4 时代，赶在 GPT-5 之前把治理、应急预案、狼来了的信用账都理清楚，对整个行业未必是坏事。
